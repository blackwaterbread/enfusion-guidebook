---

이 부록은 Arma Reforger Tools 1.8.0.13 화면을 기준으로 메뉴 항목을 화면 이름 그대로 모은 것입니다. 항목은 메뉴에 나오는 순서대로 적었고, 메뉴 안의 구분선은 ` / `로 나타냈습니다. ▸는 하위 메뉴가 있는 항목이고, 하위 메뉴의 항목은 싣지 않았습니다. 흐리게 표시되는 항목도 함께 적었습니다.

**다루는 장** 열의 "—"는 이 책에서 다루지 않는 항목입니다. 항목 열이 "—"인 메뉴는 이 부록에 항목을 싣지 않은 메뉴입니다. 메뉴 옆의 단축키는 부록 A에 있습니다.

**File** 메뉴에는 프로젝트 설정(**Project Settings...**)과 Workbench 설정(**Options...**)이 따로 있습니다(<FigRef id="apb-main-file" />). 위키(Workbench Plugin)에 따르면 **Plugins** 메뉴의 항목은 스크립트로 만든 플러그인입니다. 위 표는 의존성이 Arma Reforger 하나인 프로젝트의 메뉴입니다.

### 메뉴로 여는 창

- **File > Project Settings...**: 위쪽에 **ID**, **GUID**, **TITLE**, **Dependencies**가 있고, 아래쪽에는 **Configuration** 펼침 목록에서 고른 구성의 설정이 **General**, **Engine**, **Modules** 같은 묶음으로 있습니다. 문자열 테이블 목록 **String Tables**는 **Modules** 아래 **Widget Manager Settings** 안에 있습니다. 1·2·10장에서 다룹니다.
- **File > Options...**: 왼쪽 범주는 **General**, **World Editor**, **Animation Editor**, **Script Editor**, **Audio Editor**, **Behavior Editor**, **Shortcuts**입니다. **General** 범주에는 **Net API**, **Language Server Protocol**, **Autosave** 같은 묶음이 있고, 창 왼쪽 아래에는 **Register "enfusion://" Protocol**과 **Export All Settings** 버튼이 있습니다. 2장에서 다루고, **Language Server Protocol**은 4장에서 봅니다.

열린 탭이 없을 때 메인 창 가운데에는 시작 화면이 있습니다. **QUICK LAUNCH**에 **Editors** 메뉴와 같은 편집기 버튼 여덟 개가 있고, 그 아래에 **LINKS**와 **NEWS**가 있습니다(2장).

## Resource Browser

메인 창과 World Editor의 Resource Browser 아래쪽에는 **Import** 버튼과 **Create** ▾ 버튼이 있습니다.

| 메뉴 | 항목 | 다루는 장 |
|---|---|---|
| **Create** ▾ | **Create Folder** 묶음: **New Folder** / **Create Resource** 묶음: **Config file**, **Game material**, **GUI image set**, **GUI layout**, **GUI string table**, **GUI style**, **Material**, **Particle effect**, **Physics material**, **Ragdoll definition**, **Script**, **Vehicle contact surface** | 3장(Script는 4장, Config file은 9장, GUI layout과 GUI string table은 10장) |
| 파일 오른쪽 클릭(기본 게임 프리팹) | **Open File in New Tab** / **Explore** 묶음: **Show in Explorer**, **Navigate to Folder** / **Common** 묶음: **Register**, **Register and Import**, **Reimport**, **Tags** ▸, **Duplicate**, **Inherit**, **Delete**, **Rename** / **Addons** 묶음: **Navigate to Original**, **Navigate to Ancestor**, **Navigate to Override**, **Override in '…'**, **Duplicate to '…'**, **Inherit in '…'** / **Utils** 묶음: **Copy Resource Name(s)**, **Copy Resource GUID(s)**, **Copy Link**, **Copy File Path(s)**, **Send to...** ▸, **Find References**, **Find Inherited Files**, **Refresh Thumbnail(s)**, **Edit Prefab(s)**, **Save Changes**, **Revert Changes** / **Script** 묶음: **Plugins** ▸ | 3장(Override in, Duplicate to, Inherit in은 8장에도) |

**Addons** 묶음의 따옴표 안에는 작업 중인 프로젝트의 ID가 들어갑니다. 기본 게임 파일에서는 흐리게 표시되는 항목이 많습니다(<FigRef id="apb-rb-context" />). 작업 중인 프로젝트에 이미 덮어쓴 원본 파일에서는 <strong>Override in '…'</strong>이 없고 **Navigate to Override**를 고를 수 있습니다. 덮어쓴 파일 쪽의 메뉴에서는 **Addons** 묶음에 Navigate 세 항목만 남고, **Navigate to Original**과 **Navigate to Ancestor**를 고를 수 있습니다.

메뉴의 항목은 파일 종류와 어느 창의 Resource Browser인지에 따라서도 다릅니다. 메인 창에서 프리팹과 모델(`.xob`)의 메뉴 끝에는 **Script** 묶음이 있고, 설정 파일과 레이아웃의 메뉴에는 없습니다. 모델의 **Addons** 묶음에는 Navigate 세 항목만 있고, 소리 파일(`.wav`)과 소리 프로젝트(`.acp`)에는 <strong>Inherit in '…'</strong>이 없습니다. World Editor 창의 Resource Browser에서는 맨 위의 **Open File in New Tab**과 **Utils** 묶음 끝의 **Save Changes**, **Revert Changes**가 없고, 설정 파일과 프리팹의 메뉴 끝에 **Custom** 묶음이 붙습니다(부록 C의 Resource Manager 항목).

<Figure src="shared/rb-context-base-prefab.png" alt="기본 게임 프리팹의 오른쪽 클릭 메뉴" id="apb-rb-context">기본 게임 프리팹의 오른쪽 클릭 메뉴</Figure>

## String Editor

| 메뉴 | 항목 | 다루는 장 |
|---|---|---|
| **File** | **New**, **Open**, **Save** / **Exit** | 10장 |

## Diag Menu

Play 중에 <Kbd>Win</Kbd>+<Kbd>Alt</Kbd>로 여는 게임 안의 메뉴입니다. 메뉴 이름은 화면 글자 그대로 코드 글꼴로 적었습니다.

| 메뉴 | 항목 | 다루는 장 |
|---|---|---|
| 맨 위 목록 | `Statistics`, `Render`, `Scene`, `World`, `Animation`, `Physics`, `Game`, `Sounds`, `Particles`, `Vehicles`, `GameCode`, `Cheats`, `Character`, `Serialization`, `AI`, `Platform`, `Systems`, `Notifications`, `Extras`, `UI`, `Input`, `Replication`, `GameMode`, `Editor`, `ScenarioFramework` | 11장 |
| `Statistics` | 스크립트와 관련된 항목: `Slow script`, `Verbose script Print`, `Script profiler`, `Script prof. external` | 11장 |
| `GameCode` | 하위 메뉴 `User Actions`(그 안에 `Log actions`, `Context position`), `Network`(그 안에 `Log ownership changes`) | 11장 |
| `UI` | 셋째 줄 `Disable Loc` | 10·11장 |

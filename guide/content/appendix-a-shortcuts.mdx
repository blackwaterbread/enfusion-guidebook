description: 메인 창, Script Editor, World Editor, String Editor와 Play 중에 쓰는 단축키를 창별로 모았습니다. 메뉴에 적혀 있기만 한 키는 비고 칸에 따로 표시했습니다.
---

이 부록은 Arma Reforger Tools 1.8.0.13 화면을 기준으로 단축키를 창별로 모은 것입니다. 메뉴 항목 옆에 적힌 키는 화면 글자 그대로 옮겼고, 메뉴에 없는 키도 함께 실었습니다. 메뉴 전체는 부록 B, 위키 이름과 화면 이름이 다른 곳은 부록 C에 있습니다.

비고 칸이 빈 키는 눌러서 동작을 확인한 키이고, '메뉴 표시'는 메뉴 항목 옆에 적혀 있는 키입니다.

동작 열은 메뉴 이름을 우리말로 옮긴 것이고, 기능의 자세한 설명은 본문 각 장에 있습니다.

<Note title="키는 창마다 다릅니다">

단축키는 그 키가 적힌 창을 활성 창으로 두고 누릅니다. Script Editor의 <Kbd>F4</Kbd>, <Kbd>F5</Kbd>, <Kbd>F9</Kbd>, <Kbd>F10</Kbd>도 Script Editor가 활성 창일 때 동작합니다. 같은 키가 창마다 다른 일을 하기도 합니다. 예를 들어 <Kbd>F10</Kbd>은 Script Editor에서는 **Debug > Step Over**이고, Play 중에는 게임의 일시정지 메뉴를 엽니다. <Kbd>Ctrl</Kbd>+<Kbd>B</Kbd>는 메인 창에서 **Locate File in Resource Browser**, Script Editor에서 **Navigate To File**, World Editor에서 **Bake MLOD Texture**, String Editor에서 **Build Runtime Table** 옆에 적혀 있습니다. <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>D</Kbd>는 Script Editor의 **Plugins** 메뉴에서 **Debug Line Shortcut** 옆에 적혀 있고, World Editor에서는 Dedicated Server Tool을 실행합니다(12장).

</Note>

<Note title="위키 단축키 표와 다른 곳">

위키(Script Editor)의 단축키 표는 이전 책갈피(Previous Bookmark)를 <Kbd>Shift</Kbd>+<Kbd>F7</Kbd>로 적지만, 화면에서 <Kbd>Shift</Kbd>+<Kbd>F7</Kbd>은 **Build > Validate and Reload Scripts**의 키이고 **Previous Bookmark** 옆에는 <Kbd>Alt</Kbd>+<Kbd>F2</Kbd>가 적혀 있습니다. 같은 표는 다음 책갈피를 <Kbd>F2</Kbd>로 적지만, <Kbd>F2</Kbd>를 눌러도 다음 책갈피로 가지 않습니다. 다음 책갈피는 <Kbd>Shift</Kbd>+<Kbd>F2</Kbd>입니다. 같은 표의 Open File(<Kbd>Ctrl</Kbd>+<Kbd>O</Kbd>)은 Script Editor의 메뉴에 없습니다. 같은 표가 Compile, Insert Breakpoint, Compile current file on host (game)라고 부르는 항목은 화면의 메뉴에서 **Validate Scripts**, **Toggle Breakpoint**, **Recompile File on Host**입니다(부록 C).

</Note>

## Play 중

Play 중에 게임 화면과 Diag Menu에서 쓰는 키입니다. 플레이 모드를 끝내는 <Kbd>Esc</Kbd>는 위 World Editor 표에 있습니다. Diag Menu는 Play 중 World Editor 뷰포트에 뜨는 게임 안의 메뉴라, 메뉴 위치는 그 안의 경로를 코드 글꼴로 적었습니다.

위키(Diag Menu)는 메뉴 안의 키를 <Kbd>Win</Kbd>+<Kbd>Alt</Kbd> 없이 적지만, Diag Menu는 <Kbd>Win</Kbd>+<Kbd>Alt</Kbd>를 누른 채로 보고 다룹니다(11장). 같은 문서의 Hotkeys List에는 `Statistics`의 세 키 말고도 디버그 기능의 단축키가 더 있습니다. {/* 확인 대기: Hotkeys List의 키 */}

<Warning title="화살표와 Windows 창 정렬">

Windows 11에서는 <Kbd>Win</Kbd>+<Kbd>Alt</Kbd>를 누른 채 화살표를 누르면 Diag Menu도 움직이지만, Windows의 창 정렬도 함께 일어나 World Editor 창이 화면 아래쪽 절반이나 오른쪽, 왼쪽에 붙습니다. Diag Menu를 다루는 방법은 11장에서 설명합니다.

</Warning>

## 단축키 설정

메인 창의 **File > Options...** 창 왼쪽 목록에는 **Shortcuts** 범주가 있습니다(2장). 이 범주의 단축키 목록은 **Camera**, **Common**, **Resource Manager**, **World Editor**, **Script Editor** 같은 묶음으로 나뉩니다. 예를 들어 메인 창 **Edit** 메뉴의 **Locate File in Resource Browser**는 **Resource Manager** 묶음에 있습니다. 항목의 키 칸을 누르면 `Press new shortcut`이 표시되고, 이때 새 키를 누르면 그 키로 바뀝니다. 바꾼 칸은 이름이 굵게 보이고 오른쪽에 되돌리기 화살표(6장)가 붙습니다. **OK**로 창을 닫으면 메뉴 항목 옆에 적힌 키도 새 키로 바뀝니다. 위키(Resource Manager: Options)는 검색 칸 옆의 **Reset All** 버튼으로 모든 키를 기본값으로 되돌린다고 설명합니다. 위키(Workbench Plugin)는 플러그인의 단축키를 플러그인 스크립트에 적는다고 설명합니다.

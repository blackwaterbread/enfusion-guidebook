<Objectives>

- World Editor 창에서 Hierarchy, 뷰포트, Object Properties, Resource Browser를 찾을 수 있다.
- 월드를 열고, 기존 월드를 바탕으로 새 월드를 만들어 프로젝트에 저장하는 흐름을 설명할 수 있다.
- Hierarchy에서 엔티티를 골라 Object Properties에서 컴포넌트와 속성을 볼 수 있다.
- Resource Browser의 프리팹(`.et`)과 모델(`.xob`)을 뷰포트로 끌어다 놓아 엔티티를 만들 수 있다.
- 속성 이름이 굵게 보이는 것이 무엇을 뜻하는지 설명할 수 있다.

</Objectives>

World Editor는 월드(`.ent`)를 편집하는 편집기입니다. 월드에 엔티티를 놓고, 엔티티에 붙은 컴포넌트의 값을 고치고, 그 월드에서 게임을 실행합니다. Script 책의 예제는 대부분 "테스트 월드를 열고, 엔티티에 컴포넌트를 붙인 다음 Play를 누른다"로 실행하므로 이 장의 화면을 가장 자주 보게 됩니다.

이 장은 월드와 엔티티까지 다룹니다. 컴포넌트를 더하고 속성 칸을 채우는 방법은 7장, 프리팹 파일을 만들고 고치는 방법은 8장, 게임 실행(Play)은 11장에서 다룹니다. 엔티티와 컴포넌트가 무엇인지는 Script 책 10장에 있습니다.

## World Editor 열기

메인 창의 **Editors** 메뉴에서 **World Editor**를 고르면 World Editor 창이 열립니다. Resource Browser에서 월드 파일(`.ent`)을 두 번 클릭해도 그 월드가 World Editor에서 열립니다. World Editor는 메인 창과 따로 뜨는 창입니다.

창 제목은 `World Editor - ` 뒤에 프로젝트 ID와 연 월드 파일의 경로가 붙은 꼴입니다. 저장하지 않은 변경이 있으면 제목 끝에 `*`가 붙습니다.

메뉴 막대에는 **File**, **Edit**, **View**, **Game**, **Tools**, **Window**, **Plugins**, **Entities**, **Help** 아홉 개가 있습니다. 메인 창(2장)과 달리 **Editors**와 **Utilities** 메뉴가 없고, 대신 **Game**, **Tools**, **Entities** 메뉴가 있습니다.

## 창의 구성

World Editor 안의 창은 <FigRef id="ch06-overview" />에서 다음 자리에 있습니다. 창 사이의 경계를 끌면 창이 넓어지거나 좁아집니다.

| 번호 | 자리 | 창 | 하는 일 |
|---|---|---|---|
| 1 | 왼쪽 | **Hierarchy**(아래에 **Create** 탭) | 월드에 있는 엔티티의 목록 |
| 2 | 가운데 | 뷰포트(위에 **Camera**, **Shading**, **Placement**, **Selection** 탭) | 월드를 3D로 보여 주는 화면 |
| 3 | 아래 | **Resource Browser**, **Prefab Library**, **Log Console** 탭 | 파일 찾기와 끌어다 놓기, 로그 |
| 4 | 오른쪽 위 | **Object Properties**(옆에 **Move** 탭) | 고른 엔티티의 컴포넌트와 속성 |
| 5 | 오른쪽 아래 | **Terrain Minimap** | 지형 미니맵. 이 책에서는 쓰지 않음 |

창 맨 아래 상태 줄의 오른쪽 끝에는 `Version 1.8.0.13 (production)`처럼 Workbench의 버전이 표시됩니다. 도구 막대에는 게임을 실행하는 초록색 삼각형 모양의 Play 버튼이 있고, 그 오른쪽의 ▾를 눌러 여는 Play 목록에서 실행 방식을 고릅니다(11장).

## 월드 열기와 새 월드

### 월드 열기

월드를 여는 방법은 두 가지입니다.

- Resource Browser에서 `.ent` 파일을 두 번 클릭합니다.
- World Editor의 **File > Load World**(메뉴 표시: <Kbd>Ctrl</Kbd>+<Kbd>O</Kbd>)를 고릅니다. **Load world** 창이 뜨고, 창에는 검색 칸과 폴더·`.ent` 파일의 나무, **OK**와 **Cancel** 버튼이 있습니다.

World Editor의 **File** 메뉴에는 **New World**, **Load World**, **Save World**, **Save with Options**, **Save World As** 같은 항목과 최근에 연 월드가 있습니다(<FigRef id="ch06-file-menu" />). 최근 월드 항목을 누르면 그 월드가 열립니다. 지금 월드에 저장하지 않은 변경이 있으면 먼저 저장할지 묻는 창이 뜹니다(이 장 끝의 "월드 저장"). 저장 항목도 그 절에서 봅니다.

<Figure src="ch06/file-menu.png" alt="World Editor의 File 메뉴" id="ch06-file-menu">World Editor의 File 메뉴</Figure>

### 새 월드 만들기

예제를 시험할 월드는 위키의 튜토리얼들처럼 기본 게임의 월드를 바탕으로 새로 만들어 자기 프로젝트에 저장합니다. 기본 게임의 파일은 고쳐 쓰지 않습니다.

World Editor의 **File > New World**(메뉴 표시: <Kbd>Ctrl</Kbd>+<Kbd>N</Kbd>)를 고르면 새 월드의 종류를 묻는 **Create world** 창이 뜹니다(<FigRef id="ch06-new-world" />). 창의 **world type** 묶음에서 **Base scene**과 **Sub-scene (of current world)** 가운데 하나를 고르고 **OK**를 누릅니다. 처음에는 **Base scene**이 골라져 있습니다. 두 종류는 위키(New Terrain Setup)가 이렇게 설명합니다.

- **Sub-scene (of current world)**: 지금 열려 있는 지형 위에 "레이어를 하나 더 얹는" 새 월드를 만듭니다.
- **Base scene**: 아무것도 없이 처음부터 시작하는 월드를 만듭니다. 위키는 이어서 지형 엔티티부터 놓는 순서를 안내합니다.

예제를 시험하는 데는 Sub-scene이면 충분합니다. 기본 게임의 MpTest 월드를 부모로 만든 월드 파일(`.ent`)에는 다음처럼 부모 월드를 가리키는 내용만 들어 있습니다.

```text
SubScene {
 Parent "{96A8AF57260A7392}worlds/MP/MpTest/MpTest.ent"
}
```

이런 월드를 열면 Hierarchy 맨 위에 부모 월드(`MpTest`)와 이 월드가 따로 보이고, 둘 다 아래에 `default` 레이어가 있습니다. 부모 월드의 레이어에는 자물쇠 아이콘이 붙어 있습니다. 이 레이어의 엔티티는 눌러서 고를 수는 있지만, Object Properties의 값이 흐리게 표시되어 고칠 수 없고 화살표를 끌어도 움직이지 않습니다.

<TryIt title="시험용 월드 만들기">

1. 메인 창의 **Editors > World Editor**로 World Editor를 엽니다.
2. World Editor 아래쪽 **Resource Browser**의 검색 칸에 `MpTest.ent`를 입력하고, 기본 게임의 `worlds/MP/MpTest/MpTest.ent`를 두 번 클릭해 엽니다. 트리에 다른 폴더가 골라져 있으면 그 폴더 안에서만 찾으므로, 파일이 보이지 않으면 트리 맨 위의 `ArmaReforger`를 누릅니다(3장). 월드가 열리면 창 제목이 `World Editor - ArmaReforger/worlds/MP/MpTest/MpTest.ent`가 됩니다.
3. World Editor의 **File > New World**를 고르고, **Create world** 창에서 <strong>Sub-scene (of current world)</strong>를 골라 **OK**를 누릅니다. 창 제목이 `World Editor - Unnamed empty world`가 되고, Hierarchy에는 `MpTest`와 새 월드 `unnamed`가 저마다 `default` 레이어와 함께 보입니다.
4. **File > Save World**(메뉴 표시: <Kbd>Ctrl</Kbd>+<Kbd>S</Kbd>)를 고르면 **Save world as** 창이 뜹니다. 폴더 나무에서 `GuideDemo` 아래 `worlds` 폴더를 고르고, **File name** 칸에 `GuideTest`를 넣어 **OK**를 누릅니다. `worlds` 폴더가 없으면 `GuideDemo`를 고른 뒤 창 아래의 **New Folder**를 눌러 **Create folder** 창에서 만듭니다. 자기 프로젝트의 폴더를 고르기 전에는 **New Folder**와 **OK**가 흐리게 표시됩니다.
5. Resource Browser에서 `GuideDemo` 아래 `worlds` 폴더에 `GuideTest.ent`와 `GuideTest_Layers` 폴더가 생겼는지 봅니다. 함께 생기는 `GuideTest.ent.meta`는 Resource Browser에 보이지 않습니다.

</TryIt>

<Figure src="ch06/new-world.png" alt="Create world 창" id="ch06-new-world">Create world 창</Figure>

MpTest를 부모로 만든 월드는 자기 레이어에 게임 모드를 놓지 않아도, Play하면 로그에 게임 모드 엔티티 `GameMode_Plain1`이 찍히고 플레이어가 만들어집니다. 부모 월드 MpTest의 `default` 레이어에 `GameMode_Plain1`이 들어 있기 때문입니다. Hierarchy에서 `MpTest` 아래의 `default`를 펼치면 보입니다. 게임 모드가 없는 월드에서 캐릭터로 시험하려면 Script 책 16장의 목록대로 게임 모드와 스폰 지점 같은 프리팹을 놓습니다. 프리팹을 놓는 방법은 이 장 뒤쪽의 "Resource Browser에서 끌어다 놓기"에서, Play는 11장에서 봅니다.

## Hierarchy

Hierarchy는 열린 월드의 내용을 나무 구조로 보여 줍니다. 맨 위에 월드, 그 아래에 레이어(layer), 레이어 아래에 엔티티가 있습니다. 위키(World Editor)는 엔티티를 레이어로 묶어 정리한다고 설명합니다. <FigRef id="ch06-hierarchy" />에서는 월드와 부모 월드가 저마다 `default` 레이어 하나로 되어 있습니다.

- 엔티티 줄을 누르면 그 엔티티가 선택되고, 오른쪽 Object Properties에 그 엔티티의 컴포넌트와 속성이 나옵니다.
- 목록에는 **name**, **prefab**, **class** 열이 있습니다. 창이 좁으면 오른쪽 열은 가로 스크롤 밖으로 가려집니다. **prefab** 열에는 그 엔티티를 만든 프리팹의 이름이, 프리팹 없이 만든 엔티티에는 `---`가 표시됩니다. **class** 열은 엔티티의 클래스(`GenericEntity` 등)입니다.
- 엔티티 이름 앞의 정육면체 아이콘 색으로도 구별합니다. **prefab** 열이 채워진 엔티티는 파란 아이콘, `---`인 엔티티는 빨간 아이콘입니다. 위키(World Editor)도 빨간색은 보통 엔티티, 파란색은 프리팹이라고 설명합니다.
- 이름을 정하지 않은 엔티티는 `GenericEntity_7`처럼 클래스 이름 뒤에, 프리팹 인스턴스라면 `TAG_GuideCrate_1`처럼 프리팹 이름 뒤에 번호가 붙은 이름으로 표시됩니다. 이런 이름은 이름을 정한 엔티티보다 흐린 글자로 보입니다.
- 월드나 레이어에 저장하지 않은 변경이 있으면 그 이름 뒤에 `*`가 붙습니다.
- 위쪽 검색 칸 옆에는 선택한 엔티티의 수가 `Selected: 1`처럼 표시됩니다.

Hierarchy에서 엔티티를 두 번 클릭하면 카메라가 그 엔티티 쪽으로 옮겨 갑니다.

Hierarchy 아래의 **Create** 탭에는 검색 칸과, `AILib`·`World` 같은 분류 아래 클래스 이름이 놓인 나무가 있습니다. 항목을 뷰포트로 끌어다 놓으면 그 클래스의 엔티티가 생깁니다. 예를 들어 `AIWaypoint`를 놓으면 Hierarchy에 `AIWaypoint_1`이 빨간 아이콘으로 생깁니다. 위키(World Editor, Prefabs Basics)는 이 목록이 스크립트로 정의한 엔티티(`EntityEditorProps`를 붙인 클래스, Script 책 10장)라고 설명합니다.

## 뷰포트

뷰포트는 월드를 3D로 보여 주는 가운데 화면입니다. 선택한 엔티티는 흰 윤곽선으로 둘러싸이고, 그 위에 빨강, 초록, 파랑 화살표가 나타납니다(<FigRef id="ch06-viewport" />). 이 화살표는 X, Y, Z 축을 뜻하는 이동 위젯이고, 화살표를 끌면 그 축을 따라 엔티티가 움직이며 Object Properties의 **Coords** 값도 바뀝니다.

엔티티를 옮기고 돌리는 도구는 **Tools** 메뉴에 있습니다. 메뉴에는 **Move**(<Kbd>W</Kbd>), **Rotate**(<Kbd>E</Kbd>), **Scale**(<Kbd>R</Kbd>), **Ground Manipulation Tool**(<Kbd>Q</Kbd>)처럼 도구 이름과 단축키가 함께 적혀 있습니다(<FigRef id="ch06-tools-menu" />). Hierarchy의 빈 곳을 한 번 누른 뒤 이 키를 눌러도 도구가 바뀝니다. 도구를 고르면 Object Properties 옆 탭이 그 도구의 창으로 바뀝니다. 평소에 보이는 **Move** 탭은 이동 도구의 창이고, 12장의 **Autotest Tool**도 이 자리에 열립니다.

카메라는 다음과 같이 움직입니다.

- 마우스 휠만 굴리면 카메라가 앞뒤로 움직입니다.
- 마우스 오른쪽 버튼을 누른 채 마우스를 움직이면 카메라 방향이 바뀌고, 그 상태에서 <Kbd>W</Kbd>·<Kbd>S</Kbd>로 앞뒤, <Kbd>A</Kbd>·<Kbd>D</Kbd>로 옆, <Kbd>Q</Kbd>·<Kbd>Z</Kbd>로 위아래로 움직입니다. 휠은 움직이는 속도를 바꿉니다.
- <Kbd>F</Kbd>를 누르면 선택한 엔티티로 카메라를 맞춥니다.

뷰포트 위의 **Camera**, **Shading**, **Placement**, **Selection** 탭은 이 책의 예제에서는 쓰지 않습니다.

## Object Properties

Object Properties는 고른 엔티티의 컴포넌트와 속성을 보여 줍니다. 위에서부터 차례로 다음이 있습니다(<FigRef id="ch06-object-properties" />).

1. 맨 위 줄: 왼쪽에 엔티티의 클래스(`GenericEntity` 등), 오른쪽에 엔티티 이름 칸이 있습니다. 이름이 없으면 `(no name)`으로 보입니다. 이름 칸에 이름을 넣고 <Kbd>Enter</Kbd>를 누르면 Hierarchy의 이름도 바뀝니다. 위키(World Editor)는 이 이름으로 스크립트에서 엔티티를 찾는다고 설명합니다.
2. **Filter Components** 검색 칸과 컴포넌트 목록: 목록 맨 위 줄은 엔티티 자신(클래스 이름)이고, 그 아래로 붙은 컴포넌트가 나열됩니다.
3. 속성 영역: 목록에서 고른 줄의 속성이 나옵니다. 위쪽에 검색 칸과 `Entity instance`라고 적힌 펼침 목록(8장), 작은 버튼 몇 개가 있습니다.
4. 맨 아래: **+ Add Component** 버튼(7장)과 **Apply to prefab** 버튼(8장)이 있습니다. 프리팹이 아닌 엔티티를 고르면 **Apply to prefab**은 흐리게 표시됩니다.

컴포넌트 목록에서 엔티티 줄을 고르면 속성 영역에 엔티티 자체의 속성이 나옵니다. **Transformation** 묶음에는 위치(**Coords**), 방향(**Angles**), 크기(**Scale**)가 있고, **General** 묶음의 **Flags**에는 **Traceable**, **Visible**, **Static**, **Feature**, **Proxy**, **Editor Only**, **Relative Y** 같은 체크 상자가 있습니다. 각 플래그의 뜻은 위키(World Editor)에 짧게 설명되어 있습니다.

목록에서 컴포넌트 줄을 고르면 속성 영역이 그 컴포넌트의 속성으로 바뀝니다(<FigRef id="ch06-component-props" />). 예를 들어 `MeshObject`를 고르면 그 엔티티의 모델이 들어 있는 **Object** 칸이 보입니다. 직접 만든 컴포넌트라면 스크립트에서 `[Attribute]`로 드러낸 값이 여기에 나옵니다. 이 칸들은 7장에서 자세히 봅니다.

값은 칸에 직접 입력해 바꿉니다. 바꾸면 창 제목에 `*`가 붙고, World Editor의 **Edit > Undo**로 되돌리면 값이 돌아오고 다른 변경이 없으면 `*`도 사라집니다. **Coords**처럼 X, Y, Z 칸이 있는 속성은 칸 앞의 축 글자를 누른 채 옆으로 끌어도 값이 바뀌고, 엔티티도 그만큼 움직입니다.

## Resource Browser에서 끌어다 놓기

World Editor 아래쪽의 **Resource Browser**는 트리가 왼쪽, 파일 목록이 오른쪽에 놓여 메인 창의 Resource Browser와 배치가 다릅니다. 트리, 검색 칸, 파일 목록, **Import**와 **Create** 버튼의 쓰임은 3장에서 다룹니다. 같은 자리의 **Log Console** 탭은 5장에서 봅니다. **Prefab Library** 탭은 게임에 들어 있는 프리팹을 분류별로 보여 주는 곳으로, World Editor에만 있습니다. 왼쪽에 `Decals`, `Generators`, `Infrastructure`, `Props`, `Rocks`, `Structures`, `Vegetation`, `Walls` 분류의 나무가, 가운데에 고른 분류의 폴더 칸이, 아래에 라이브러리를 고르는 **Library** 펼침 목록(`CainLibrary`, `DefaultLibrary`)이 있습니다.

World Editor 안에서 Resource Browser를 쓰는 주된 이유는 끌어다 놓기입니다. 무엇을 어디에 놓느냐에 따라 결과가 다릅니다.

| 끌어다 놓는 것 | 놓는 곳 | 결과 | 다루는 곳 |
|---|---|---|---|
| 프리팹(`.et`) | 뷰포트 | 그 프리팹의 인스턴스가 생김 | 이 절 |
| 모델(`.xob`) | 뷰포트 | `MeshObject`가 붙은 `GenericEntity`가 생김 | 이 절 |
| 설정 파일(`.conf`) | Object Properties의 객체 칸 | 그 설정으로 칸이 채워짐 | 7장 |
| Hierarchy의 루트 엔티티 | Resource Browser의 폴더 | 새 프리팹 파일이 생김 | 8장 |

World Editor 안의 Resource Browser에서 `.et`를 두 번 클릭하면 메인 창에 그 프리팹의 탭이 열리고, 월드에는 아무것도 생기지 않습니다(3장). 프리팹을 월드에 놓을 때는 끌어다 놓습니다. 프리팹 탭은 8장에서 봅니다.

### 프리팹 놓기

Resource Browser의 `.et` 파일을 뷰포트의 땅 위로 끌어다 놓으면 그 프리팹의 인스턴스가 월드에 생깁니다. Hierarchy에서는 파란 아이콘으로 보이고 **prefab** 열에 프리팹 이름이 표시됩니다. Script 책 16장의 시험 월드에 게임 모드와 스폰 지점 프리팹을 놓을 때도 이렇게 합니다.

### 모델 놓기

모델 파일(`.xob`)을 뷰포트로 끌어다 놓으면 `MeshObject` 컴포넌트가 붙은 `GenericEntity`가 생깁니다. 새 엔티티는 바로 선택되고, `MeshObject`의 **Object** 칸에 끌어다 놓은 모델이 들어 있습니다(<FigRef id="ch06-xob-dropped" />).

<TryIt title="모델로 엔티티 만들기">

1. 앞에서 만든 `GuideTest` 월드를 엽니다.
2. World Editor 아래쪽 **Resource Browser**의 검색 칸에 `CrateWooden_02_1x1x1.xob`를 입력합니다. 자물쇠 아이콘이 붙은 기본 게임의 나무 상자 모델이 하나 보입니다. 보이지 않으면 트리 맨 위의 `ArmaReforger`를 누릅니다.
3. 그 아이콘을 뷰포트의 땅 위로 끌어다 놓습니다. 뷰포트에 상자가 생깁니다.
4. Hierarchy에 `GenericEntity_` 뒤에 번호가 붙은 엔티티가 생기고 선택되어 있는지 봅니다. Object Properties의 컴포넌트 목록에는 `GenericEntity`와 `MeshObject`가 있습니다.
5. 목록에서 `MeshObject`를 골라 **Object** 칸에 상자 모델이 들어 있는지 봅니다.

</TryIt>

이 상자는 Script 책 16장에서 컴포넌트를 더해 보급품 상자로 만드는 엔티티의 출발점입니다. 컴포넌트를 더하는 방법은 7장, 다 꾸민 엔티티를 프리팹으로 저장하는 방법은 8장에서 봅니다.

<Figure src="ch06/xob-dropped.jpg" size="full" alt="모델을 끌어다 놓아 만든 엔티티" id="ch06-xob-dropped">모델을 끌어다 놓아 만든 엔티티</Figure>

## 굵게 보이는 속성

Object Properties의 속성 이름은 굵은 것과 보통 굵기인 것이 섞여 있습니다. 위키(Prefabs Basics)에 따르면 굵은 이름은 그 값이 이 단계에 따로 정해져 있다(덮어써져 있다)는 표시입니다. 월드에 놓인 프리팹 인스턴스라면, 프리팹이 정한 값을 이 인스턴스에서 바꾼 속성이 굵게 보입니다.

화면에서는 다음과 같이 보입니다.

- 위치만 정한 프리팹 인스턴스를 고르면 **Transformation** 가운데 **Coords**만 굵고 **Angles**와 **Scale**은 보통 굵기입니다(<FigRef id="ch06-bold-instance" />). 이런 인스턴스는 월드의 레이어 파일에도 프리팹 경로와 위치(`coords`)만 적혀 있습니다.
- 같은 인스턴스에서 컴포넌트 속성 하나의 값을 바꾸면, 그 속성과 컴포넌트 목록의 컴포넌트 이름이 굵게 바뀌고 값 오른쪽에 둥근 화살표(이 책에서는 되돌리기 화살표라고 부릅니다)가 생깁니다(<FigRef id="ch06-bold-changed" />). 변경을 되돌리면(Undo) 둘 다 다시 보통 굵기가 됩니다.
- 프리팹이 아닌 엔티티에서도 위치를 정한 **Coords**는 굵게 보입니다. `.xob`를 끌어다 놓아 막 만든 엔티티는 **Coords**, **Angles**, **Scale**이 모두 굵습니다.

메인 창에서 여는 속성 표(`.ct`, `.conf`)도 그 파일에서 정한 값을 같은 방식으로 굵게 보여 줍니다(9장).

굵은 이름을 보면 어떤 값이 이 인스턴스에서 바뀌었는지 한눈에 보입니다. 예를 들어 같은 프리팹의 인스턴스 가운데 하나만 다르게 동작한다면, 그 인스턴스에서 굵게 보이는 속성부터 확인합니다. 속성 영역 위의 `Entity instance` 펼침 목록으로 프리팹 단계의 값을 보는 방법은 8장, 되돌리기 화살표는 7장에서 다룹니다.

<Figure src="ch06/bold-instance.png" alt="프리팹 인스턴스에서 굵게 보이는 Coords" id="ch06-bold-instance">프리팹 인스턴스에서 굵게 보이는 Coords</Figure>

<Figure src="shared/we-instance-value-changed.png" alt="값을 바꾼 속성의 굵은 이름과 되돌리기 화살표" id="ch06-bold-changed">값을 바꾼 속성의 굵은 이름과 되돌리기 화살표</Figure>

## 월드 저장

저장하지 않은 변경이 있으면 창 제목 끝과 Hierarchy의 월드·레이어 이름 뒤에 `*`가 붙습니다. 월드를 저장하면 이 표시가 사라지고, World Editor의 **Edit > Undo**로 변경을 모두 되돌려도 사라집니다.

열린 월드는 World Editor의 **File > Save World**(메뉴 표시: <Kbd>Ctrl</Kbd>+<Kbd>S</Kbd>)로 저장합니다. 바꾼 것이 없을 때는 이 항목이 흐리게 표시됩니다. 같은 메뉴에는 **Save with Options**(메뉴 표시: <Kbd>Ctrl</Kbd>+<Kbd>Shift</Kbd>+<Kbd>S</Kbd>)와 다른 이름으로 저장하는 **Save World As**도 있습니다(<FigRef id="ch06-file-menu" />). **Save World As**를 고르면 새 월드를 처음 저장할 때와 같은 **Save world as** 창이 지금 월드 파일을 고른 채로 열립니다.

`worlds` 폴더에 저장한 월드는 다음과 같은 파일로 이루어집니다. 엔티티는 `.ent`가 아니라 레이어 파일(`.layer`)에 들어 있습니다.

```text
worlds/
  <이름>.ent              월드 파일(Sub-scene이면 부모 월드를 가리킴)
  <이름>.ent.meta         리소스 정보(GUID)
  <이름>_Layers/
    default.layer         default 레이어의 엔티티
```

저장하지 않은 월드가 열린 채 메인 창의 **File > Exit**로 Workbench를 끄면 **World editor - closing** 창이 뜹니다. 이 창은 저장할 월드와 레이어를 체크된 목록으로 보여 주고, 기본으로 선택된 버튼은 **Yes**입니다. **Yes**를 누르면 체크된 파일만 저장하고 닫히고, **No**를 누르면 월드를 저장하지 않고 닫힙니다(<FigRef id="ch06-closing" />).

저장하지 않은 변경이 있는 채 다른 월드를 열 때도 **Loading world** 창이 같은 꼴로 저장할지 묻습니다. 이 창에서 **Cancel**을 누르면 지금 월드가 그대로 남습니다.

Play 목록에는 **Save Changes Before Playing** 항목도 있습니다(11장).

## 정리

<Summary>

- World Editor는 메인 창의 **Editors > World Editor**나 `.ent` 파일을 두 번 클릭해 엽니다. 창 제목 끝의 `*`는 저장하지 않은 변경이 있다는 표시입니다.
- 왼쪽 Hierarchy는 월드, 레이어, 엔티티의 나무 구조입니다. 파란 아이콘과 **prefab** 열의 이름은 프리팹 인스턴스, 빨간 아이콘과 `---`는 보통 엔티티입니다.
- 오른쪽 Object Properties의 컴포넌트 목록에서 줄을 고르면 그 엔티티나 컴포넌트의 속성이 아래에 나옵니다.
- 예제를 시험할 월드는 기본 게임 월드를 바탕으로 **File > New World**의 Sub-scene으로 만들어 자기 프로젝트에 저장합니다.
- Resource Browser의 `.et`를 뷰포트로 끌어다 놓으면 프리팹 인스턴스, `.xob`를 놓으면 `MeshObject`가 붙은 `GenericEntity`가 생깁니다.
- 속성 이름이 굵으면 그 값이 이 단계에 따로 정해져 있다는 뜻입니다. 프리팹 인스턴스에서는 인스턴스에서 바꾼 값이 굵게 보입니다.
- 월드는 **File > Save World**로 저장합니다. 엔티티는 `.ent` 옆 `_Layers` 폴더의 레이어 파일에 들어 있습니다.

</Summary>

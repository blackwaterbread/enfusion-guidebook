## 이런 분을 위한 책입니다

- 프로그래밍 지식이 어느 정도 있는 분. 변수, 함수, 클래스가 무엇인지는 안다고 보고 설명합니다. C#을 써 봤다면 문법이 꽤 익숙하게 느껴질 것입니다.
- Arma Reforger 모딩은 처음인 분. 엔진 구조는 필요한 만큼 함께 설명하고, Workbench는 예제를 실행하는 데 필요한 만큼만 짧게 안내합니다. 자세한 Workbench 사용법은 같은 저자의 《Enfusion Workbench 가이드》에서 다루고, 공식 위키 문서와 함께 부록 F에 안내해 두었습니다.
- 다른 프로그래밍 언어와 무엇이 다른지 빨리 파악하고 싶은 분. 곳곳에 Python, JavaScript, C#과 나란히 비교하는 부분을 두었습니다.

이 책은 스크립트에 집중합니다. 3D 모델링, 텍스처, 지형 제작, 애니메이션 편집은 다루지 않습니다.

## 책의 구성

| 부 | 장 | 내용 |
|---|---|---|
| 1부 언어 기초 | 1–4장 | 개발 환경, 변수와 타입, 제어 흐름, 함수 |
| 2부 객체지향과 메모리 | 5–9장 | 클래스, 상속, 참조와 ARC, 컬렉션, 문자열·벡터·수학 |
| 3부 엔진 프로그래밍 | 10–13장 | 엔티티와 컴포넌트, 이벤트와 타이머, modded 클래스, UI |
| 4부 멀티플레이어와 실전 | 14–16장 | 리플리케이션, 디버깅과 테스트, 종합 실습 |
| 부록 | A–F | 언어 레퍼런스, 언어 비교표, 자주 쓰는 API, 용어집, 해답, 참고 자료 |

## 읽는 순서

처음이라면 1장부터 순서대로 읽기를 권합니다. 뒤쪽 장은 앞에서 다룬 내용을 안다고 보고 설명합니다.

다른 언어 경험이 많다면 1장을 읽은 뒤 부록 B의 비교표로 차이점을 먼저 훑어보세요. 2–6장은 빠르게 넘겨도 되지만 **7장(메모리 관리)은 꼼꼼히** 읽기 바랍니다. Enforce Script에서 버그가 가장 많이 나오는 곳이 참조와 객체 수명이고, 다른 언어에서 익힌 감각으로는 예상하기 어려운 부분이기 때문입니다. 엔진을 다루는 10장부터는 다시 순서대로 읽으면 됩니다.

참고서로 쓸 때는 다음을 활용하세요.

- **부록 A**: 키워드, 연산자, 타입, 이름 규칙 표
- **부록 C**: 분야별로 자주 쓰는 API의 시그니처와 정의 위치
- **부록 D**: 영어 문서를 읽을 때 필요한 용어 대조표
- PDF의 **책갈피와 검색**: 모든 장과 절이 책갈피에 들어 있습니다.

## 표기 규칙

코드, 키워드, 클래스 이름, 파일 이름은 `SCR_BaseGameMode`, `modded`, `addon.gproj`처럼 고정폭 글꼴로 씁니다. Workbench의 메뉴와 버튼은 화면에 보이는 영어 이름 그대로 **Script Editor**처럼 굵게 씁니다.

예제에서 직접 만드는 클래스에는 `TAG_` 접두사를 붙였습니다. 여러 모드의 클래스 이름이 부딪치지 않게 하는 공식 관례이고, `TAG`는 자리표시자입니다. 실제 모드에서는 자신만의 짧은 태그로 바꿔 쓰세요. Bohemia Interactive의 공식 스크립트에는 `SCR_` 접두사가 붙어 있습니다.

코드 블록 오른쪽 위에는 언어 이름이 붙습니다. 파일 하나를 통째로 보여 줄 때는 위쪽에 파일 경로를 함께 적습니다.

```enforce title="Scripts/Game/TAG_Example.c"
class TAG_Example
{
	void SayHello()
	{
		Print("안녕하세요");
	}
}
```

## 예제를 실행하려면

예제를 직접 실행하려면 Bohemia Interactive의 개발 도구인 **Arma Reforger Tools**가 필요합니다. Steam에서 설치하며, Workbench와 Script Editor가 여기에 들어 있습니다. 첫 프로젝트를 만들고 스크립트를 실행하는 과정은 1장에서 설명합니다.

Workbench가 없어도 1–9장의 언어 내용은 읽고 이해하는 데 문제가 없습니다. 10장부터는 엔진 위에서 동작하는 코드를 다루므로, 직접 실행해 보면 훨씬 빨리 익힐 수 있습니다.

## 근거 자료와 기준 버전

이 책은 Arma Reforger 1.8을 기준으로 합니다. 내용의 근거는 다음 네 가지입니다.

- Bohemia Interactive가 공개한 게임 스크립트 (Arma-Reforger-Script-Diff, 1.8.0.13)
- Workbench에 함께 들어 있는 Enfusion 엔진 문서
- Bohemia Interactive 커뮤니티 위키의 Arma Reforger 문서
- 공식 샘플 모드 (Arma-Reforger-Samples)

클래스와 메서드 이름, 매개변수, 열거형 값은 공식 스크립트에서 하나하나 확인하고 썼습니다. 다만 게임이 업데이트되면 API도 바뀔 수 있습니다. 책의 설명과 실제 동작이 다르면 Script Editor의 자동완성과 공식 스크립트를 기준으로 삼으세요. 근거 자료의 주소는 부록 F에 모아 두었습니다.

이 책은 비공식 학습 자료이며 Bohemia Interactive와는 관계가 없습니다.

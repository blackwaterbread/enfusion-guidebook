</Objectives>

2장에서 `string`, `vector`, 숫자 타입의 기초를 보았습니다. 이 장에서는 그 타입들을 실제로 다루는 도구를 정리합니다. 로그 메시지를 조립하고, 설정 문자열을 나누고, 두 위치 사이의 거리나 방향을 계산하고, 무작위 위치를 고르는 일은 거의 모든 모드에 나옵니다.

## 문자열 기본

`string`은 값으로 전달되는 타입입니다. 다른 변수에 대입하거나 함수에 넘기면 내용이 복사됩니다. 문자열은 `null`이 될 수 없고, 기본값은 빈 문자열입니다. 비었는지는 `IsEmpty()`로, 길이는 `Length()`로 확인합니다. 빈 문자열 상수 `string.Empty`도 있습니다.

```enforce
string name;                    // ""
bool empty = name.IsEmpty();    // true
name = "Alpha";
int length = name.Length();     // 5
string greeting = "Hello, " + name + "!\n";
```

`+`로 문자열을 이어 붙일 때 다른 타입의 값은 문자열로 바뀌어 붙습니다. 단, **왼쪽 피연산자가 문자열이어야** 합니다. `"Ammo: " + 30`은 되지만 `30 + " rounds"`는 오류입니다. 문자열 안에서는 `\n`(줄바꿈), `\r`, `\t`(탭), `\\`, `\"` 이스케이프를 쓸 수 있습니다.

### 원본을 바꾸는 메서드

다른 언어에서 넘어온 개발자가 자주 틀리는 부분입니다. Enforce Script의 `ToLower`, `ToUpper`, `Replace`, `TrimInPlace`는 **변수에 든 문자열을 직접 바꾸고**, 바뀐 문자열 대신 숫자를 반환합니다.

| 메서드 | 원본 | 반환값 |
|---|---|---|
| `ToLower()` | 소문자로 바꿈 | 길이(`int`) |
| `ToUpper()` | 대문자로 바꿈 | 길이(`int`) |
| `Replace(string sample, string replace)` | `sample`을 모두 `replace`로 바꿈 | 바꾼 횟수(`int`) |
| `TrimInPlace()` | 앞뒤 공백을 지움 | 길이(`int`) |
| `Trim()` | 그대로 둠 | 앞뒤 공백을 지운 새 문자열 |
| `Substring(int start, int len)` | 그대로 둠 | 잘라 낸 새 문자열 |

```enforce
string callsign = "  Alpha One ";

string trimmed = callsign.Trim();         // trimmed: "Alpha One", callsign은 그대로
callsign.TrimInPlace();                   // callsign: "Alpha One"
callsign.ToUpper();                       // callsign: "ALPHA ONE"
int replaced = callsign.Replace(" ", "_"); // callsign: "ALPHA_ONE", replaced: 1
```

원본은 그대로 두고 바뀐 사본이 필요하면, 공식 스크립트처럼 먼저 복사한 뒤 사본을 바꿉니다. 문자열은 값으로 복사되므로 사본을 바꿔도 원본은 그대로입니다.

```enforce
string inputLC = input; // 공식 SCR_AIGroup의 코드와 같은 형태
inputLC.ToLower();      // input은 그대로, inputLC만 소문자
```

공식 주석에 따르면 `ToLower`와 `ToUpper`는 ASCII 문자에만 동작합니다. 한글처럼 ASCII가 아닌 문자는 대소문자 변환의 대상이 아닙니다.

<Compare title="대소문자 변환 비교">

```javascript
let name = "Alpha";
let upper = name.toUpperCase(); // 새 문자열을 반환, name은 그대로
```

```csharp
string name = "Alpha";
string upper = name.ToUpper();  // 새 문자열을 반환, name은 그대로
```

```enforce
string name = "Alpha";
string upper = name;            // 사본을 만들고
upper.ToUpper();                // 사본을 직접 바꿈 (반환값은 길이)
```

</Compare>

<Pitfall title="ToUpper의 반환값을 문자열로 쓰기">

C#의 `ToUpper()`는 새 문자열을 돌려주지만, Enforce Script의 `ToUpper()`는 바꾼 뒤의 **길이**를 돌려줍니다. `Print(name.ToUpper())`라고 쓰면 대문자 이름이 아니라 숫자가 출력되고, 대신 `name` 자체가 대문자로 바뀌어 있습니다. 바뀐 문자열은 언제나 변수 쪽에 들어 있다는 점을 기억하세요.

</Pitfall>

### 부분 문자열과 검색

문자열의 위치는 0부터 셉니다. 한 글자는 `Get(i)`나 `[i]`로 읽으며, 결과는 길이 1인 문자열입니다.

| 메서드 | 반환 | 설명 |
|---|---|---|
| `Substring(int start, int len)` | `string` | `start`부터 `len`글자 |
| `IndexOf(string sample)` | `int` | 처음 나오는 위치, 없으면 -1 |
| `LastIndexOf(string sample)` | `int` | 마지막으로 나오는 위치, 없으면 -1 |
| `IndexOfFrom(int start, string sample)` | `int` | `start`부터 찾은 위치, 없으면 -1 |
| `Contains(string sample)` | `bool` | 포함 여부 |
| `ContainsAt(string sample, int pos)` | `bool` | `pos` 위치에 `sample`이 있는지 |
| `StartsWith(string sample)` | `bool` | `sample`로 시작하는지 |
| `EndsWith(string sample)` | `bool` | `sample`로 끝나는지 |

`Substring`의 두 번째 인수는 끝 위치가 아니라 **글자 수**입니다. C#의 `Substring`과 같고, JavaScript의 `substring(start, end)`와는 다릅니다. 공식 주석의 예로 `"Hello World".Substring(2, 5)`는 `"llo W"`입니다.

다음은 `"Alpha-1"` 같은 분대 표기를 이름과 번호로 나누는 함수입니다.

```enforce
class TAG_SquadParser
{
	static bool ParseSquad(string text, out string squad, out int number)
	{
		int dash = text.IndexOf("-");
		if (dash <= 0)
			return false;

		squad = text.Substring(0, dash);
		number = text.Substring(dash + 1, text.Length() - dash - 1).ToInt();
		return true;
	}
}
```

`TAG_SquadParser.ParseSquad("Alpha-1", squad, number)`는 `true`를 반환하고 `squad`에 `"Alpha"`, `number`에 1을 넣습니다. `out` 매개변수는 4장에서 다뤘습니다.

### 분할과 결합

`Split(delimiter, outTokens, skipEmptyEntries)`는 구분자로 문자열을 나눠 배열에 채웁니다. 결과를 받을 배열은 `notnull out`으로 선언되어 있으므로 **미리 만들어 둔 배열**을 넘겨야 합니다. 세 번째 인수에는 기본값이 없으므로, 빈 조각을 버릴지(`true`) 남길지(`false`) 꼭 적어야 합니다. 반대로 `string.Join(separator, tokens, skipEmptyEntries)`는 배열을 구분자로 이어 붙인 문자열을 돌려주는 정적 메서드입니다.

```enforce
array<string> parts = {};
string line = "Alpha,Bravo,,Charlie";
line.Split(",", parts, true);              // "Alpha", "Bravo", "Charlie"

string joined = string.Join(" / ", parts, false); // "Alpha / Bravo / Charlie"
```

### 비교

`==`와 `!=`는 대소문자를 구분해 내용이 같은지 비교합니다. 대소문자를 무시하고 비교하려면 `Compare(sample, caseSensitive)`의 두 번째 인수에 `false`를 줍니다. `Compare`는 같으면 0, 사전 순으로 앞이면 0보다 작은 값, 뒤면 0보다 큰 값을 반환합니다.

```enforce
bool same = ("Hello" == "hello");                   // false
bool sameIgnoringCase = ("Hello".Compare("hello", false) == 0); // true
```

### 숫자와 문자열 변환

숫자를 문자열로 바꿀 때는 `+`로 이어 붙이거나 `ToString`을 씁니다. `int.ToString(len, hex, prefix)`는 길이에 맞춰 앞을 0으로 채우거나 16진수로 바꿀 수 있고, `float.ToString(len, lenDec)`은 전체 길이와 소수부 길이를 정할 수 있습니다. 결과는 공식 주석의 예와 같습니다.

```enforce
int num = 123;
string a = num.ToString();      // "123"
string b = num.ToString(5);     // "00123"
string c = num.ToString(len: 4, hex: true, prefix: "#"); // "#007B"

float value = 123.456;
string d = value.ToString(10, 4); // "00123.4560"
```

`len: 4`처럼 `이름: 값` 형태로 쓴 인수는 4장에서 배운 이름 있는 인수(named argument)입니다.

문자열을 숫자로 바꿀 때는 `ToInt`와 `ToFloat`를 씁니다. 두 메서드 모두 앞쪽 공백을 건너뛰고 숫자를 읽습니다. `ToInt`는 숫자를 읽지 못하면 `default` 인수(생략하면 0)를 돌려줍니다.

```enforce
int a = "42".ToInt();                 // 42
int b = " 42abc".ToInt();             // 42: 숫자 뒤의 글자는 무시
int c = "abc42".ToInt();              // 0: 읽기 실패
int d = "abc42".ToInt(17);            // 17: 실패하면 default
float e = "42.7".ToFloat();           // 42.7
vector f = "1 0 1".ToVector();        // 벡터로 변환
```

`"0"`처럼 정말 0인 값과 읽기 실패를 구별하려면 `parsed` 출력 인수를 씁니다. 읽은 글자 수가 들어오므로 0이면 숫자가 없었다는 뜻입니다.

```enforce
int parsedChars;
int value = text.ToInt(parsed: parsedChars);
if (parsedChars == 0)
	Print("not a number: " + text, LogLevel.WARNING);
```

## 문자열 형식화

### string.Format과 PrintFormat

`string.Format(fmt, ...)`은 형식 문자열의 `%1`부터 `%9`까지를 뒤따르는 인수로 바꾼 새 문자열을 돌려줍니다. 인수는 최대 9개이고 타입은 무엇이든 됩니다. `PrintFormat`은 같은 형식으로 만든 문자열을 바로 로그에 출력합니다.

```enforce
string report = string.Format("%1 has %2 rounds", "Alpha", 24); // "Alpha has 24 rounds"
PrintFormat("%2 rounds left for %1", "Alpha", 24);              // 번호 순서는 자유
```

자리표시자 번호는 인수의 순서를 가리키므로 형식 문자열 안에서 순서를 바꿔 써도 됩니다. 그래서 어순이 다른 언어로 문장을 옮길 때도 형식 문자열만 바꾸면 됩니다.

퍼센트 기호를 그대로 출력하려면 `%%`로 씁니다. 위키 문서는 `PrintFormat("5%%")`가 `5%`를 출력한다고 설명하고, 공식 다운로드 진행률 표시 코드도 `string.Format("%1 %%", ...)`를 씁니다. `Print`에는 형식 처리가 없으므로 `%`를 그대로 씁니다.

```enforce
string progress = string.Format("%1%%", 80); // "80%"
```

<Pitfall title="PrintFormat에 LogLevel을 위치 인수로 넘기기">

`PrintFormat`의 선언은 `PrintFormat(string fmt, void param1 = NULL, ..., void param9 = NULL, LogLevel level = LogLevel.NORMAL)`입니다. 형식 인수 뒤에 `LogLevel.WARNING`을 그냥 이어 쓰면 `level`이 아니라 다음 자리표시자 인수(`param2` 등)로 들어가 버립니다. 로그 수준은 공식 스크립트처럼 이름 있는 인수로 넘기세요.

```enforce
PrintFormat("No ammo for %1", weaponName, LogLevel.WARNING);        // 잘못: param2로 들어감
PrintFormat("No ammo for %1", weaponName, level: LogLevel.WARNING); // 올바름
```

로그 수준의 의미와 로그를 읽는 방법은 15장에서 다룹니다.

</Pitfall>

<Note title="출력 길이 제한">

공식 주석에 따르면 `string.Format`, `Substring`, `Trim`이 만드는 문자열은 최대 8191자로 제한됩니다. 아주 긴 텍스트를 한 번에 조립하는 경우가 아니라면 신경 쓸 일은 드뭅니다.

</Note>

### 화면에 보이는 문장과 로컬라이즈 키

로그가 아니라 플레이어 화면에 보이는 문장은 코드에 영어나 한국어를 직접 쓰지 않습니다. `#AR-`로 시작하는 **로컬라이즈 키**를 쓰고, 실제 문장은 언어별 번역 파일에서 가져옵니다. 공식 `SCR_StringHelper.IsTranslationKey`의 주석도 `#AR-Translation_Value_3` 같은 형태를 예로 듭니다. 번역 파일과 UI에서 키를 쓰는 방법은 13장에서 다룹니다.

### SCR_StringHelper

Game 모듈에는 문자열 도우미 `SCR_StringHelper`가 있습니다. 엔진 기본 메서드에 없는 기능이 필요할 때 먼저 찾아볼 만합니다. 몇 가지만 소개합니다.

| 메서드 | 설명 |
|---|---|
| `PadLeft(string input, int length, string padding = " ")` | 왼쪽을 채워 길이를 맞춤. `PadLeft("7", 3, "0")`은 `"007"` |
| `PadRight(string input, int length, string padding = " ")` | 오른쪽을 채움 |
| `IsEmptyOrWhiteSpace(string input)` | 비었거나 공백뿐인지 |
| `TrimLeft(string input)`, `TrimRight(string input)` | 한쪽 공백만 지운 새 문자열 |
| `CountOccurrences(string haystack, string needle, bool caseInsensitive = false)` | 등장 횟수 |
| `Join(string separator, array<int> pieces)` | 정수 배열 결합(`float`, `bool` 버전도 있음) |

## 벡터

### 만들기와 성분

`vector`는 `float` 세 개로 이루어진 3차원 벡터이며, 위치·방향·속도·각도를 표현합니다. 문자열처럼 값으로 다루는 타입이라 대입하거나 함수에 넘기면 복사되고, 기본값은 세 성분이 모두 0입니다. 만드는 방법은 세 가지입니다.

```enforce
vector a = "1 2 3";              // 공백으로 구분한 문자열 리터럴
vector b = {1, 2, 3};            // 중괄호 리터럴
vector c = Vector(x, y, z);      // 변수나 식으로 만들 때
vector d = {Math.Cos(angle), 0, Math.Sin(angle)}; // 중괄호 안에도 식을 쓸 수 있음
```

문자열 리터럴 안에는 변수를 쓸 수 없으므로, 계산한 값으로 벡터를 만들 때는 `Vector(x, y, z)`나 중괄호를 씁니다. 공식 스크립트도 세 형태를 모두 씁니다.

성분은 인덱스로 읽고 씁니다. `v[0]`이 X, `v[1]`이 Y, `v[2]`가 Z입니다. Enfusion에서는 **Y축이 위쪽**입니다. 공식 주석도 위쪽 벡터를 (0, 1, 0)으로 설명합니다. 자주 쓰는 방향은 상수로 준비되어 있습니다: `vector.Up`, `vector.Right`, `vector.Forward`, `vector.Zero`, `vector.One`.

```enforce
vector position = "100 5 200";
float height = position[1];    // 5
position[1] = height + 2;      // Y만 바꿈
```

### 연산자

| 연산 | 예 | 결과 |
|---|---|---|
| 벡터 + 벡터, 벡터 - 벡터 | `target - origin` | 성분별 덧셈·뺄셈 |
| 벡터 * 실수, 실수 * 벡터 | `direction * 10` | 크기 조절 |
| 벡터 / 실수 | `size / 2` | 크기 조절 |
| 단항 - | `-direction` | 반대 방향 |
| `==`, `!=` | `a == b` | 세 성분이 모두 같은지 |

`+=`, `-=`, `*=`, `/=`도 같은 규칙으로 씁니다. 공식 스크립트에서 방향에 거리를 곱해 위치에 더하거나(`arrowStartPos + arrowLength * sectorDir`), 크기를 반으로 나누거나(`m_vSize / 2`), 값을 누적하는(`m_vBoundsMin += worldBoundBoxMin`) 코드를 흔히 볼 수 있습니다.

<Warning title="벡터끼리 곱하는 * 는 쓰지 마세요">

두 벡터 사이의 `*` 연산자는 공식 문서에 설명이 없습니다. 내적이 필요하면 `vector.Dot(a, b)`를, 외적이 필요하면 Game 모듈의 `SCR_Math3D.Cross(a, b)`를 써서 의도를 분명히 하세요. `==` 비교도 실수 오차 때문에 계산 결과에는 잘 맞지 않습니다. 두 위치가 "같은지"는 거리가 아주 작은지로 판단합니다.

</Warning>

### 길이, 거리, 정규화

| 메서드 | 반환 | 설명 |
|---|---|---|
| `v.Length()` | `float` | 길이 |
| `v.LengthSq()` | `float` | 길이의 제곱 |
| `vector.Distance(a, b)` | `float` | 두 점 사이 거리 |
| `vector.DistanceSq(a, b)` | `float` | 거리의 제곱 |
| `vector.DistanceXZ(a, b)` | `float` | 높이(Y)를 빼고 X·Z만으로 잰 거리 |
| `v.Normalize()` | 없음 | `v`를 길이 1로 **직접** 바꿈 |
| `v.Normalized()` | `vector` | 길이 1인 새 벡터. `v`는 그대로 |
| `v.NormalizeSize()` | `float` | `v`를 직접 정규화하고 원래 길이를 반환 |
| `vector.Direction(from, to)` | `vector` | `from`에서 `to`로 가는 벡터. 정규화되지 않음 |
| `vector.Lerp(a, b, t)` | `vector` | 두 벡터 사이 선형 보간 |

`Distance`는 제곱근을 계산하므로, "범위 안에 있는가"처럼 크기만 비교할 때는 제곱 거리를 반지름의 제곱과 비교하는 편이 가볍습니다. 공식 `SCR_Math3D.ClampMagnitude`도 `v.LengthSq() > magnitude * magnitude`로 비교합니다.

```enforce
class TAG_RangeUtils
{
	static bool IsWithinRange(vector a, vector b, float range)
	{
		return vector.DistanceSq(a, b) <= range * range;
	}
}
```

문자열 메서드와 마찬가지로 `Normalize()`는 반환값 없이 **원본을 직접 바꿉니다**. 공식 주석의 예로 `"1 0 1"`을 정규화하면 X와 Z가 약 0.707, Y가 0인 벡터가 되고, 원래 길이는 약 1.414입니다.

```enforce
vector offset = target - origin;
vector dir = offset.Normalized(); // offset은 그대로
offset.Normalize();               // 이제 offset 자체가 길이 1
```

### 내적과 외적

`vector.Dot(a, b)`는 두 벡터의 **내적**을 돌려줍니다. 두 벡터가 모두 길이 1이면 내적은 사잇각의 코사인입니다. 그래서 대상이 앞쪽에 있는지, 시야각 안에 있는지 판단할 때 자주 씁니다.

```enforce
class TAG_ViewUtils
{
	//! 대상이 forward 방향 기준 좌우 halfAngleDeg도 안에 있으면 true입니다.
	static bool IsInFront(vector eyePos, vector forward, vector targetPos, float halfAngleDeg)
	{
		vector toTarget = vector.Direction(eyePos, targetPos).Normalized();
		float cosAngle = vector.Dot(forward.Normalized(), toTarget);
		return cosAngle >= Math.Cos(halfAngleDeg * Math.DEG2RAD);
	}
}
```

사잇각 자체가 필요하면 `Math.Acos`로 되돌립니다. 실수 오차로 내적이 1을 아주 조금 넘을 수 있으므로 `Math.Clamp(cosAngle, -1, 1)`로 범위를 맞춘 뒤 넘기는 것이 안전합니다. 결과는 라디안이므로 `Math.RAD2DEG`를 곱해 도로 바꿉니다.

**외적**은 엔진 `vector` 클래스에 메서드가 없고, Game 모듈의 `SCR_Math3D.Cross(vector first, vector second, bool normalizeVectors = false)`가 제공합니다. 두 벡터에 수직인 벡터가 필요할 때 씁니다. 위쪽 벡터와의 외적은 `v.Perpend()`로도 구할 수 있습니다.

### 방향과 각도

Enfusion은 각도를 도(degree) 단위의 요(yaw), 피치(pitch), 롤(roll)로 다루는 메서드를 제공합니다. 반면 `Math`의 삼각 함수는 라디안을 씁니다. 둘 사이는 `Math.DEG2RAD`와 `Math.RAD2DEG`로 바꿉니다.

| 메서드 | 설명 |
|---|---|
| `v.ToYaw()` | XZ 평면에서 본 방향의 요(도) |
| `vector.FromYaw(float yaw)` | 요(도)를 XZ 평면의 방향 벡터로 |
| `v.VectorToAngles()` | 방향 벡터를 (요, 피치, 롤) 각도 벡터로 |
| `v.AnglesToVector()` | (요, 피치, 롤) 각도 벡터를 길이 1인 방향 벡터로 |

공식 주석의 예에 따르면 `"1 0 0"`의 `ToYaw()`는 90이고, `vector.FromYaw(90)`은 `<1,0,0>`, `vector.FromYaw(45)`는 X와 Z가 각각 약 0.707인 벡터입니다. 즉 요 90도는 +X 방향입니다. 한 위치에서 다른 위치를 바라보는 요는 다음처럼 구합니다.

```enforce
float yaw = vector.Direction(origin, target).ToYaw();
```

엔티티의 현재 각도를 얻는 `GetYawPitchRoll()`과 변환 행렬은 10장에서 다룹니다.

## Math와 Math3D

### 상수와 자주 쓰는 함수

`Math`는 정적 메서드와 상수만 가진 클래스입니다. 상수는 `Math.PI`, `Math.PI2`(2π), `Math.PI_HALF`(π/2), `Math.RAD2DEG`, `Math.DEG2RAD`, `Math.E`가 있습니다.

| 함수 | 설명 |
|---|---|
| `Round(f)`, `Floor(f)`, `Ceil(f)` | 반올림, 내림, 올림. 결과는 `float` |
| `Min(x, y)`, `Max(x, y)` | 작은 값, 큰 값(`float`). 정수용은 `MinInt`, `MaxInt` |
| `AbsFloat(f)`, `AbsInt(i)` | 절댓값 |
| `Clamp(value, min, max)` | 범위 안으로 자름. 정수용은 `ClampInt` |
| `Lerp(a, b, t)`, `InverseLerp(a, b, value)` | 선형 보간과 그 역 |
| `Map(value, fromLow, fromHigh, toLow, toHigh)` | 한 범위의 값을 다른 범위로 옮김 |
| `Sqrt(val)`, `Pow(v, power)` | 제곱근, 거듭제곱 |
| `Sin`, `Cos`, `Tan`, `Asin`, `Acos`, `Atan2(y, x)` | 삼각 함수(라디안) |
| `Mod(v, div)` | 실수 나머지 |
| `Repeat(value, range)` | 0과 `range` 사이로 감아 돌림. `Repeat(370, 360)`은 10, `Repeat(-20, 360)`은 340 |
| `IsInRange(value, min, max)` | 양 끝을 포함해 범위 안인지 |

`%` 연산자는 정수에만 쓸 수 있으므로 실수에는 `Mod`나 `Repeat`를 씁니다. 공식 `SCR_Math`의 주석에 따르면 `Math.Mod(-500, 360)`은 -140입니다. 결과의 부호가 나누어지는 수(-500)를 따르는 것입니다. 각도처럼 항상 0 이상이어야 하는 값은 `Repeat`로 감는 편이 안전합니다.

`Round`, `Floor`, `Ceil`은 `float`를 반환하지만, 결과를 `int` 변수에 대입하면 정수로 들어갑니다. 공식 스크립트도 `int count = Math.Ceil(value);`처럼 씁니다.

### 난수

| 함수 | 범위 |
|---|---|
| `Math.RandomInt(min, max)` | 정수, `min` 이상 `max` 미만 |
| `Math.RandomIntInclusive(min, max)` | 정수, `min` 이상 `max` 이하 |
| `Math.RandomFloat(min, max)` | 실수, `min` 이상 `max` 미만 |
| `Math.RandomFloatInclusive(min, max)` | 실수, `min` 이상 `max` 이하 |
| `Math.RandomFloat01()` | 실수, 0 이상 1 이하 |
| `Math.RandomGaussFloat(sigma, mean)` | 정규분포. 표준편차가 먼저, 평균이 나중 |

`Math.RandomInt(0, 2)`는 0이나 1이고, 2는 나오지 않습니다. 배열에서 무작위 원소를 고를 때는 8장의 `GetRandomElement()`를 써도 됩니다.

같은 순서의 난수를 다시 얻어야 한다면 시드를 정할 수 있는 `RandomGenerator` 객체를 씁니다. `Math.Randomize(seed)`는 공식 정의에서 "시드가 필요하면 `RandomGenerator`를 쓰라"는 `Obsolete` 표시가 붙어 있습니다.

```enforce
RandomGenerator generator = new RandomGenerator();
generator.SetSeed(1234);
int roll = generator.RandIntInclusive(1, 6);      // 1~6
float chance = generator.RandFloat01();           // 0~1
vector spot = generator.GenerateRandomPointInRadius(10, 50, center); // center 둘레 10~50 m
```

`GenerateRandomPointInRadius`는 공식 주석대로 XZ 성분만 채우고 Y는 0으로 두므로, 높이는 따로 정해야 합니다. 공식 스크립트는 생성기를 `protected ref RandomGenerator m_pRandomGenerator = new RandomGenerator();`처럼 멤버로 두고 재사용합니다.

### Math3D와 SCR_Math3D

`Math3D`에는 행렬, 쿼터니언, 교차 판정 함수가 모여 있습니다. 위치와 회전을 담는 변환 행렬은 10장에서 본격적으로 다루므로 여기서는 이름만 익혀 둡니다.

| 함수 | 설명 |
|---|---|
| `Math3D.AnglesToMatrix(vector ang, out vector mat[3])` | (요, 피치, 롤) 각도로 회전 행렬을 만듦 |
| `Math3D.MatrixToAngles(vector mat[3])` | 회전 행렬을 각도로 |
| `Math3D.MatrixIdentity4(out vector mat[4])` | 단위 행렬 |
| `Math3D.DirectionAndUpMatrix(vector dir, vector up, out vector mat[])` | 방향과 위쪽 벡터로 회전 행렬 |

## 시간 값 다루기

### 월드 시간

게임 로직에서 시간을 잴 때는 보통 **월드 시간**을 씁니다. `BaseWorld.GetWorldTime()`은 월드가 만들어진 뒤 흐른 시간을 밀리초 단위 `float`로 돌려줍니다. 공식 스크립트는 `GetGame().GetWorld().GetWorldTime()`으로 읽습니다. 월드가 없는 상황도 있으므로 `GetWorld()`의 결과는 확인하고 씁니다.

```enforce
class TAG_Stopwatch
{
	protected float m_fStartTime;

	//------------------------------------------------------------------------------------------------
	void Start()
	{
		World world = GetGame().GetWorld();
		if (world)
			m_fStartTime = world.GetWorldTime();
	}

	//------------------------------------------------------------------------------------------------
	//! 시작한 뒤 흐른 시간(초)입니다.
	float GetElapsedSeconds()
	{
		World world = GetGame().GetWorld();
		if (!world)
			return 0;

		return (world.GetWorldTime() - m_fStartTime) / 1000;
	}
}
```

밀리초를 `float`에 담으면 정밀도에 한계가 있습니다. 공식 `WorldTimestamp` 문서는 밀리초를 `float`에 담을 때 반올림 없이 담을 수 있는 최댓값이 16,777,216밀리초(약 4.5시간)라고 설명합니다. 오래 도는 서버에서 정확한 시각 비교가 필요하면 `WorldTimestamp`를 씁니다.

```enforce
ChimeraWorld world = ChimeraWorld.CastFrom(GetGame().GetWorld());
if (world)
{
	WorldTimestamp readyAt = world.GetServerTimestamp().PlusSeconds(30);
	// ... 나중에 확인
	bool ready = world.GetServerTimestamp().GreaterEqual(readyAt);
}
```

`WorldTimestamp`에는 `PlusSeconds`, `PlusMilliseconds`, `DiffSeconds`, `DiffMilliseconds`, `Greater`, `GreaterEqual`, `Less`, `LessEqual`, `Equals` 같은 메서드가 있습니다. 공식 주석에 따르면 `GetServerTimestamp()`는 서버에서는 로컬 타임스탬프(`GetLocalTimestamp()`)와 같고, 클라이언트에서는 네트워크 지연을 고려해 서버의 현재 시각을 예측한 값입니다. 이 값은 앞으로 건너뛰거나 느려지고 빨라질 수는 있어도 뒤로 가지는 않습니다.

### 시스템 시간과 게임 속 시각

`System` 클래스는 실제 세계의 시간을 다룹니다.

| 함수 | 설명 |
|---|---|
| `System.GetTickCount()` | 게임이 시작된 뒤 흐른 밀리초(`int`) |
| `System.GetUnixTime()` | 1970년 1월 1일 UTC부터 흐른 초 |
| `System.GetHourMinuteSecond(out int hour, out int minute, out int second)` | 현재 현지 시각 |
| `System.GetYearMonthDay(out int year, out int month, out int day)` | 현재 현지 날짜 |

UTC가 필요하면 `GetHourMinuteSecondUTC`, `GetYearMonthDayUTC`를 씁니다. 실행 시간을 재거나 로그에 실제 시각을 남길 때 유용하지만, 게임 로직의 타이밍에는 월드 시간을 씁니다.

게임 속 하루의 시각(낮과 밤)은 월드의 시간·날씨 관리자에서 얻습니다. `ChimeraWorld.GetTimeAndWeatherManager()`가 돌려주는 `TimeAndWeatherManagerEntity`의 `GetTimeOfTheDay()`는 0.0부터 24.0 사이의 시간(시 단위 실수)을, `GetHoursMinutesSeconds(out hours, out minutes, out seconds)`는 시·분·초를 돌려줍니다.

```enforce
ChimeraWorld world = ChimeraWorld.CastFrom(GetGame().GetWorld());
if (!world)
	return;

TimeAndWeatherManagerEntity manager = world.GetTimeAndWeatherManager();
if (manager)
{
	int hours, minutes, seconds;
	manager.GetHoursMinutesSeconds(hours, minutes, seconds);
	PrintFormat("In-game time %1:%2", hours, minutes.ToString(2));
}
```

`minutes.ToString(2)`는 분을 두 자리로 맞춥니다. 일정 시간 뒤에 함수를 실행하거나 주기적으로 반복하는 타이머는 11장에서 다룹니다.

## 정리

<Summary>

- `string`은 값으로 전달되고 null이 될 수 없습니다. `+`로 이어 붙일 때는 왼쪽이 문자열이어야 하고, `==`는 대소문자를 구분합니다.
- `ToLower`, `ToUpper`, `Replace`, `TrimInPlace`는 원본을 직접 바꾸고 숫자(길이나 횟수)를 반환합니다. `Trim`과 `Substring`은 새 문자열을 반환합니다. 사본이 필요하면 먼저 복사한 뒤 바꿉니다.
- `Substring(start, len)`의 두 번째 인수는 글자 수입니다. 검색 메서드는 못 찾으면 -1을 반환합니다. `Split`에는 미리 만든 배열을 넘깁니다.
- `string.Format`과 `PrintFormat`은 `%1`~`%9`를 인수로 바꾸며, `%` 자체는 `%%`로 씁니다. 화면용 문장에는 로컬라이즈 키를 씁니다(13장).
- `vector`는 `"x y z"`, `{x, y, z}`, `Vector(x, y, z)`로 만들고 `v[0]`~`v[2]`로 성분을 다룹니다. Y축이 위쪽입니다.
- 벡터의 길이·거리·정규화는 `Length`, `vector.Distance`, `Normalized`로 구하고, 범위 비교에는 제곱 거리를 씁니다. `Normalize()`는 원본을 바꿉니다. 내적은 `vector.Dot`, 외적은 `SCR_Math3D.Cross`입니다.
- `Math`는 삼각 함수(라디안), 반올림, 범위 제한, 보간, 난수를 제공합니다. 시드가 필요한 난수는 `RandomGenerator`를 씁니다.
- 게임 로직의 시간은 월드 시간(`GetWorldTime()`, 밀리초)을 쓰고, 오래 도는 경우의 정확한 비교에는 `WorldTimestamp`를 씁니다.

</Summary>

- `Trigger()`는 지금부터 대기를 시작합니다.
- `IsReady()`는 대기가 끝났거나 한 번도 시작하지 않았으면 `true`를 반환합니다.
- `GetStatusText()`는 준비되었으면 `"Ready"`, 아니면 남은 시간을 올림한 정수 초로 `"Wait 3 s"`처럼 반환합니다.

월드가 없을 때도 null 접근 오류가 나지 않게 하세요.

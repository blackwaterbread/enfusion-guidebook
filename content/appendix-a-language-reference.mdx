이 부록은 Arma Reforger 1.8.0.13 기준입니다. Workbench에 들어 있는 엔진 문서(Syntax, Keywords, Operators, Values), 공식 위키(Scripting: Keywords, Operators, Values, Conventions, Preprocessor Directives), 공식 스크립트를 대조해 정리했습니다. 표의 마지막 열은 자세히 설명한 장입니다.

## 키워드

키워드는 식별자(변수, 함수, 클래스 이름)로 쓸 수 없습니다. 아래 표는 엔진 문서와 위키의 키워드 목록에, 공식 Workbench 플러그인 `SCR_ClassRenamingPlugin.c`가 클래스 이름 충돌을 막으려고 갖고 있는 키워드 배열(`KEYWORDS`)을 더해 정리했습니다.

### 선언 키워드

| 키워드 | 뜻 | 예 | 장 |
|---|---|---|---|
| `class` | 클래스를 선언합니다. | `class TAG_Item` | 5장 |
| `enum` | 열거형을 선언합니다. | `enum TAG_EState` | 2장 |
| `typedef` | 타입에 별칭을 붙입니다. | `typedef array<string> TStringArray;` | 8장 |
| `extends` | 상속을 나타냅니다. `:`와 같습니다. | `class B extends A` | 6장 |
| `modded` | 기존 클래스(또는 열거형)를 같은 이름으로 바꿔 끼웁니다. | `modded class SCR_BaseGameMode` | 12장 |
| `sealed` | 클래스에 붙이면 상속할 수 없고, 메서드에 붙이면 오버라이드할 수 없습니다. | `sealed class TAG_Final` | 6장 |

### 메서드 수식어

| 키워드 | 뜻 | 장 |
|---|---|---|
| `static` | 객체 없이 `클래스이름.메서드()`로 부릅니다. 정적 메서드 안에서는 정적 멤버만 쓸 수 있습니다. | 4장, 5장 |
| `override` | 부모 클래스의 메서드를 다시 정의합니다. 컴파일러가 부모에 같은 시그니처의 메서드가 있는지 검사합니다. | 6장 |
| `private` | 같은 클래스의 메서드에서만 부를 수 있습니다. `modded` 클래스는 쓸 수 있지만 자식 클래스는 쓸 수 없습니다. | 5장, 12장 |
| `protected` | 같은 클래스, 자식 클래스, `modded` 클래스에서 부를 수 있습니다. | 5장 |
| `event` | 엔진이 콜백으로 부르는 메서드를 표시합니다. 엔티티에서는 도구에 스크립트 이벤트로 보여 주라는 힌트이기도 합니다. | 10장 |
| `proto` | 엔진(C++) 쪽에 구현된 함수를 스크립트에 공개합니다. 공식 선언에서만 봅니다. | 1장 |
| `native` | 내부 함수의 네이티브 호출 규약입니다. 공식 선언에서만 봅니다. | 없음 |
| `external` | `proto` 함수를 API에 연결하라는 컴파일러 힌트입니다. | 없음 |
| `volatile` | 스크립트로 다시 콜백할 수 있는 내부 함수라는 컴파일러 힌트입니다. | 없음 |

### 변수와 매개변수 수식어

| 키워드 | 뜻 | 장 |
|---|---|---|
| `const` | 상수입니다. 다시 대입할 수 없습니다. 객체에 붙이면 참조만 고정되고 내용은 바꿀 수 있습니다. | 2장 |
| `static` | 인스턴스가 아니라 클래스에 속하는 값입니다. 공개 정적 변수는 `클래스이름.변수`로 씁니다. | 5장 |
| `private`, `protected` | 멤버 변수의 접근 제한자입니다. 둘은 함께 쓸 수 없습니다. | 5장 |
| `ref` | 강한 참조입니다. 이 참조가 남아 있는 동안 객체가 살아 있습니다. | 7장 |
| `autoptr` | Managed가 아닌 객체를 변수 수명이 끝날 때 자동으로 삭제합니다. Managed 객체에는 `ref`를 씁니다. | 7장 |
| `out` | 함수가 값을 채워 돌려주는 매개변수입니다(참조로 전달). | 4장 |
| `inout` | 함수가 값을 읽은 뒤 바꾸는 매개변수입니다(참조로 전달). | 4장 |
| `notnull` | `null`이 오면 가상 머신 예외가 나고 메서드가 실행되지 않습니다. | 4장 |
| `owned` | 내부 함수가 돌려준 문자열이나 배열을 VM이 해제하지 않게 합니다. 공식 선언에서만 봅니다. | 없음 |
| `reference` | Material 편집기에서 머티리얼 매개변수로 쓸 수 있다는 도구용 힌트입니다. | 없음 |

### 코드 키워드

| 키워드 | 뜻 | 장 |
|---|---|---|
| `new` | 클래스의 인스턴스를 만듭니다. 공식 컨벤션은 `new TAG_Item()`처럼 괄호를 붙이라고 정합니다. | 5장 |
| `delete` | 객체를 즉시 지우고, `delete`한 변수와 그 객체를 가리키던 약한 참조를 `null`로 만듭니다. 다른 강한 참조(지역 변수, `ref` 멤버, `array<ref T>`의 원소 등)가 남아 있으면 지우지 못하고 VM 예외가 납니다. | 7장 |
| `null` | 아무 객체도 가리키지 않는 값입니다. | 2장 |
| `this` | 메서드가 속한 객체입니다. 위키에 따르면 1.1.0부터 정적 메서드에서는 현재 타입을 뜻합니다. | 5장 |
| `super` | 부모 클래스의 멤버를 가리킵니다. | 6장 |
| `vanilla` | `modded` 클래스 안에서 모드가 적용되지 않은 원래 버전의 멤버를 가리킵니다(위키: 1.1.0부터). | 12장 |
| `thread` | 메서드를 협력형 스크립트 스레드로 실행합니다. Workbench 플러그인용이며 게임 코드에서는 `CallLater`를 씁니다. | 4장 |
| `auto` | 대입하는 값으로 타입을 추론합니다. 공식 Best Practices는 쓰지 말라고 권합니다. | 2장 |
| `debug` | Script Editor에서 브레이크포인트를 겁니다. 공식 코드는 `debug;` 문장으로 씁니다. | 15장 |
| `true`, `false` | `bool` 리터럴입니다. | 2장 |

공식 엔진 선언(`proto` 함수)은 기본값으로 `NULL`을 쓰기도 하지만, 스크립트 코드는 거의 언제나 소문자 `null`을 씁니다.

### 흐름 제어 키워드

| 키워드 | 뜻 | 장 |
|---|---|---|
| `if`, `else` | 조건에 따라 실행합니다. `else if`로 조건을 이어 갑니다. | 3장 |
| `switch`, `case`, `default` | 정수, 열거형, 문자열 값으로 분기합니다. | 3장 |
| `for` | 초기화, 조건, 갱신으로 반복합니다. | 3장 |
| `foreach` | 배열, `set`, `map`의 원소를 차례로 돕니다. 구분자는 `:`입니다. | 3장 |
| `while` | 조건이 참인 동안 반복합니다. | 3장 |
| `break` | 가장 안쪽의 반복문이나 `switch`를 빠져나갑니다. | 3장 |
| `continue` | `for`, `foreach`, `while`에서 다음 반복으로 넘어갑니다. | 3장 |
| `return` | 함수를 끝내고, 값이 있으면 돌려줍니다. | 4장 |

### 기본 타입 이름

`int`, `float`, `bool`, `string`, `vector`, `typename`은 기본 타입입니다. 공식 스크립트 `Core/generated/Types/`에 `sealed class int`처럼 선언되어 있으며, 그 안에 `ToString()` 같은 메서드와 `int.MAX` 같은 상수가 들어 있습니다. `void`는 반환값이 없음을 나타내고, 엔진 함수 선언의 매개변수 타입으로 쓰이면 어떤 타입이든 받는다는 뜻입니다(`Print(void var, ...)`). 동적 배열 `array`, 집합 `set`, 맵 `map`, 모든 클래스의 뿌리 `Class`, 참조 카운팅을 쓰는 `Managed`, 함수 타입 `func`는 `Core/proto/Types.c`에 선언된 클래스입니다.

### 다른 언어에는 있지만 Enforce Script에는 없는 것

| 문법 | 상태 | 대신 쓰는 것 | 장 |
|---|---|---|---|
| 삼항 연산자 `? :` | 엔진 문서가 지원하지 않는다고 명시(컴파일 오류) | `if`/`else` | 2장 |
| `do`/`while` | 문서와 공식 스크립트에 없음 | `while (true)`와 `break` | 3장 |
| `try`, `catch`, `throw` | 키워드 목록에 없음 | `null` 검사, 반환값으로 실패 알리기 | 3장, 15장 |
| `import`, `using`, `namespace` | 키워드 목록에 없음 | 모듈 전체를 함께 컴파일, 태그 접두사 | 1장 |
| `interface`, `abstract`, `virtual` | 키워드 목록에 없음 | 메서드는 기본적으로 오버라이드할 수 있음(엔진 문서). 추상 클래스는 관례로 대신 | 6장 |
| 람다, 익명 함수 | 문서와 공식 스크립트에 없음 | 메서드 이름을 `func`로 넘김 | 4장, 11장 |
| `goto`, 레이블 `break` | 문서와 키워드 목록에 없음 | 플래그 변수, 메서드로 분리 | 3장 |
| 가변 인수 | 엔진 문서가 없다고 명시 | 배열 매개변수 | 4장 |
| `async`, `await` | 없음 | 콜 큐의 `CallLater` | 11장 |
| `char`, `double`, `long` 타입 | 없음 | `string`, `float`, `int` | 2장 |
## 연산자

### 우선순위 표

엔진 문서와 위키는 연산자 우선순위가 C 언어와 같다고 설명합니다. 위키의 표는 순위 번호가 중간에 어긋나 있어서, 아래 표는 C의 순서대로 번호를 다시 매겼습니다. 숫자가 작을수록 먼저 계산됩니다.

| 순위 | 연산자 | 뜻 | 결합 방향 |
|---|---|---|---|
| 1 | `++` `--`(후위), `()`, `[]`, `.` | 후위 증감, 함수 호출, 인덱스, 멤버 접근 | 왼쪽에서 오른쪽 |
| 2 | `++` `--`(전위), `+` `-`(단항), `!`, `~`, `new`, `delete` | 전위 증감, 부호, 논리 부정, 비트 부정, 생성, 삭제 | 오른쪽에서 왼쪽 |
| 3 | `*` `/` `%` | 곱셈, 나눗셈, 나머지 | 왼쪽에서 오른쪽 |
| 4 | `+` `-` | 덧셈, 뺄셈, 문자열 연결 | 왼쪽에서 오른쪽 |
| 5 | `<<` `>>` | 비트 시프트 | 왼쪽에서 오른쪽 |
| 6 | `<` `<=` `>` `>=` | 크기 비교 | 왼쪽에서 오른쪽 |
| 7 | `==` `!=` | 같음, 다름 | 왼쪽에서 오른쪽 |
| 8 | `&` | 비트 AND | 왼쪽에서 오른쪽 |
| 9 | `^` | 비트 XOR | 왼쪽에서 오른쪽 |
| 10 | `\|` | 비트 OR | 왼쪽에서 오른쪽 |
| 11 | `&&` | 논리 AND | 왼쪽에서 오른쪽 |
| 12 | `\|\|` | 논리 OR | 왼쪽에서 오른쪽 |
| 13 | `=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `^=` `\|=` | 대입, 복합 대입 | 오른쪽에서 왼쪽 |

- `==`가 `&`보다 먼저 계산되므로 비트 검사는 `(flags & mask) == mask`처럼 괄호로 묶습니다.
- 형변환 `(int)`, `(float)`는 표에 없지만, 공식 코드의 `return (float)milliseconds / 1000;`처럼 바로 뒤의 피연산자에 먼저 적용되는 것으로 씁니다.
- `%=`와 `^=`는 위키의 우선순위 표에만 나오고 공식 스크립트에서는 쓰이지 않습니다. 나머지 복합 대입 연산자는 문서 예제나 공식 코드에서 확인할 수 있습니다.

### 연산자별 동작

| 연산자 | 피연산자 | 동작과 주의점 | 장 |
|---|---|---|---|
| `/` | 숫자 | 둘 다 `int`인 식을 `int` 변수에 담거나 `Print`·`PrintFormat`에 넘기면 소수 부분을 버립니다. 결과를 `float`로 받으면(변수, 스크립트 함수의 매개변수, 반환값) 실수로 계산됩니다(1.8.0.13 실행). 하나라도 `float`이면 `float`입니다. | 2장 |
| `%` | 정수 | 정수에만 씁니다. 실수는 `Math.Mod(float v, float div)`를 씁니다. | 2장 |
| `++` `--` | `int`, `float` 변수 | 전위는 바뀐 값, 후위는 바뀌기 전 값을 식의 결과로 돌려줍니다. | 2장 |
| `+` | 문자열 | 왼쪽이 `string`이면 오른쪽 값을 문자열로 바꿔 잇습니다. `3 + "test"`는 오류입니다. | 2장 |
| `==` `!=` | 모든 타입 | `bool`, 숫자, `string`(대소문자 구분), `vector`는 값을 비교하고 배열과 객체는 같은 객체인지 비교합니다. `10 == 10.0`은 참입니다. | 2장 |
| `&&` `\|\|` | `bool` | 왼쪽만으로 결과가 정해지면 오른쪽을 계산하지 않습니다. | 2장, 3장 |
| `!` | `bool`, 숫자, 문자열, 객체 | 숫자는 0인지, 문자열은 비었는지, 객체는 `null`인지 봅니다. 객체가 아니면 명시적 비교를 권합니다. | 2장, 3장 |
| `>>` | 정수 | 부호 비트를 유지합니다. `0x80000000`을 8비트 밀면 `0xFF800000`입니다. | 2장 |
| `[]` | 배열, 문자열, 벡터, 맵 | 0부터 시작하는 인덱스입니다. 문자열은 한 글자짜리 문자열을, 벡터는 성분을 돌려줍니다. 맵에서는 `myMap["key"]`가 키로 값을 찾습니다. | 2장, 8장 |

## 기본 타입

### 타입별 크기와 기본값

| 타입 | C++ 대응 | 범위 | 기본값 | 크기 | 전달 | 멤버 변수 접두사 |
|---|---|---|---|---|---|---|
| `int` | int32 | −2,147,483,648부터 2,147,483,647까지 | `0` | 4바이트 | 값 | `i` |
| `float` | float | 최대 약 ±3.402823E+38 | `0.0` | 4바이트 | 값 | `f` |
| `bool` | bool | `true`, `false` | `false` | 4바이트 | 값 | `b` |
| `string` | char* | 없음 | `""` | 포인터 8바이트와 문자열 길이 | 값 | `s` |
| `vector` | float[3] | `float`와 같음 | 세 성분 모두 0 | 포인터 8바이트와 12바이트 | 값 | `v` |
| 열거형 | int | `int`와 같음 | `0` | 4바이트 | 값 | `e` |
| `typename` | VarType* | 없음 | `typename.Empty` | 8바이트 | 참조 | 없음 |
| 클래스 | Instance* | 없음 | `null` | 8바이트 | 참조 | 없음 |
| `array` | 없음 | 없음 | `null` | 없음 | 참조 | `a` |
| `map` | 없음 | 없음 | `null` | 없음 | 참조 | `m` |
| `set` | 없음 | 없음 | `null` | 없음 | 참조 | 없음 |

- 크기와 범위는 엔진 문서의 표를 따랐습니다. `float`의 가장 작은 양수 범위는 엔진 문서의 두 페이지(Syntax와 Values)가 서로 다르게 적고 있어 최댓값만 적었습니다.
- `typename`의 기본값을 엔진 문서 표는 `null`로 적지만, 위키는 `typename.Empty`라고 설명하고 공식 코드도 언제나 `typename.Empty`와 비교합니다.
- 열거형의 크기는 문서에 따로 적혀 있지 않습니다. 엔진 문서가 열거형을 `int` 상수의 집합이라고 설명하므로 `int`와 같게 적었습니다.

| 10진 정수 | `42`, `-7` | |
| 16진 정수 | `0xFF`, `0xFFF22613` | 공식 색 상수가 이 형태입니다. |
| 실수 | `2.5`, `0.333`, `1.0e-8`, `1e-12` | 공식 코드는 `f` 접미사 없이 씁니다. |
| bool | `true`, `false` | |
| null | `null` | 객체, 배열, `set`, `map`에만 씁니다. |
| 문자열 | `"Hello"`, `"Tab\there"` | 이스케이프는 `\n`, `\r`, `\t`, `\\`, `\"`입니다. |
| 벡터 | `"0 1 0"`, `{ 0, 1.5, 2 }` | 중괄호 형태는 계산식도 넣을 수 있습니다. `Vector(x, y, z)` 함수도 있습니다. |
| 배열 초기화 | `{ 1, 2, 3 }`, `{}` | 위키에 따르면 줄 안에서 바로 초기화할 수 있는 컬렉션은 배열뿐입니다. |
| 타입 | `TAG_Item`, `typename.Empty` | 클래스 이름을 그대로 `typename`에 대입합니다. |
| 열거형 값 | `TAG_EWeather.RAIN` | `열거형이름.값` 형태로 씁니다. |

문자 하나를 나타내는 따옴표 리터럴(`'a'`)은 없습니다. 문자열의 한 글자는 `text[0]`처럼 한 글자짜리 `string`으로 다룹니다.

### 형변환 요약

| 변환 | 방법 | 결과와 주의점 | 장 |
|---|---|---|---|
| `int`에서 `float` | 그냥 대입 | `float f = 1;`은 1.0 | 2장 |
| `float`에서 `int` | 대입 또는 `(int)` | 소수 부분을 버림(반올림 아님) | 2장 |
| 반올림, 내림, 올림 | `Math.Round`, `Math.Floor`, `Math.Ceil` | `float`를 돌려주며 `int`에 바로 넣을 수 있음 | 2장 |
| 숫자에서 문자열 | `"text" + value`, `value.ToString()` | `int.ToString(len, hex, prefix)`, `float.ToString(len, lenDec)` | 2장 |
| 문자열에서 숫자 | `text.ToInt()`, `text.ToFloat()` | `ToInt`는 앞 공백을 건너뛰고 숫자가 아닌 글자에서 멈춤. 실패하면 `default`, 읽은 글자 수는 `parsed` | 2장 |
| 문자열에서 벡터 | `text.ToVector()` | `"1 0 1"` 형태 | 9장 |
| 문자열과 타입 | `text.ToType()`, `type.ToString()` | 없는 이름이면 `typename.Empty` | 2장 |
| 열거형과 문자열 | `typename.EnumToString(E, v)`, `typename.StringToEnum(E, name)` | 플래그 조합은 `SCR_Enum.FlagsToString` | 2장 |
| 부모 타입에서 자식 타입 | `Child.Cast(obj)` | 실패하면 `null` | 6장 |

## 전처리기

### 지시문

엔진 문서와 위키가 설명하는 전처리기 지시문은 여섯 가지입니다.

| 지시문 | 뜻 |
|---|---|
| `#define 이름` | 플래그를 정의합니다. 플래그는 정의되었거나 정의되지 않았거나 둘 중 하나입니다. |
| `#ifdef 이름` | 플래그가 정의되어 있으면 아래 코드를 컴파일합니다. `#endif`로 닫습니다. |
| `#ifndef 이름` | 플래그가 정의되어 있지 않으면 아래 코드를 컴파일합니다. `#endif`로 닫습니다. |
| `#else` | 바로 앞의 `#ifdef`나 `#ifndef`와 반대 조건의 코드를 시작합니다. |
| `#endif` | 전처리기 블록을 닫습니다. |
| `#include` | 다른 파일의 내용을 이 자리에 붙여 넣은 것처럼 만듭니다. 공식 스크립트에서는 쓰이지 않습니다. |

`#if`, `#elif`, `#undef`는 문서에도 공식 스크립트에도 나오지 않습니다.

```enforce
#ifdef WORKBENCH
	// Workbench에서 실행할 때만 컴파일되는 코드
#else
	// 그 밖의 경우
#endif
```

위키(Scripting Temporary Feature)에 따르면 플래그를 정의하는 방법은 두 가지입니다.

- 파일 맨 위에 `#define TAG_MY_FEATURE`를 씁니다. 위키는 이 플래그를 쓰는 **모든 파일**에 각각 적으라고 합니다. 1.8에서 시험해 보면 한 파일의 `#define`이 같은 모듈의 다른 파일에도 적용되지만, 파일 순서에 기대지 말고 플래그를 쓰는 파일마다 적습니다.
- 실행 파일에 `-scrDefine TAG_MY_FEATURE` 시작 매개변수를 붙입니다. 엔진 명령줄 문서에 따르면 이 매개변수는 `-configuration`과 함께 쓸 수 없습니다.

위키는 Script Editor가 `#ifdef` 블록 안의 오류를 언제나 제대로 찾아 주지는 못한다고도 경고합니다. 꺼진 블록의 코드는 컴파일되지 않으므로, 플래그를 켠 상태로도 컴파일해 봐야 합니다.

### 자주 보는 플래그

| 플래그 | 뜻 | 공식 스크립트의 `#ifdef`/`#ifndef` 사용 횟수 |
|---|---|---|
| `WORKBENCH` | Workbench 실행 파일에서 실행 중일 때 정의됩니다(위키). Workbench 전용 코드를 게임에서 빼는 데 씁니다. | 470여 번 |
| `ENABLE_DIAG` | 공식 코드가 진단(diag) 메뉴와 디버그용 코드를 감싸는 데 씁니다. | 280여 번 |

### 매크로

| 매크로 | 바뀌는 값 |
|---|---|
| `__FILE__` | 현재 파일의 상대 경로 문자열 |
| `__LINE__` | 현재 줄 번호를 담은 문자열 |

공식 코드는 경고 로그에 위치를 남길 때 두 매크로를 함께 씁니다.

```enforce
Print("Cannot load " + selectedPrefab + " | " + FilePath.StripPath(__FILE__) + ":" + __LINE__,
	LogLevel.WARNING);
```

## 언어 수준 어트리뷰트

어트리뷰트는 대괄호로 클래스, 메서드, 변수에 메타 정보를 붙이는 문법입니다. 엔진 문서에 따르면 어트리뷰트도 평범한 스크립트 클래스이고, 컴파일 직후 선언마다 한 번 인스턴스가 만들어집니다. Workbench에 속성을 보여 주는 `[Attribute(...)]`는 10장에서 다루며, 여기서는 언어 자체의 동작에 관여하는 두 가지만 정리합니다.

| 어트리뷰트 | 정의된 곳 | 뜻 |
|---|---|---|
| `[Obsolete("메시지")]` | `Core/generated/Attributes/Obsolete.c` | 메서드를 더 이상 쓰지 말라고 표시합니다. 부르는 곳에서 컴파일 경고가 나지만 메서드는 정상적으로 실행됩니다. |
| `[Friend(ClassName)]` | `Core/generated/Attributes/Friend.c` | 지정한 클래스가 이 클래스의 `protected` 메서드를 부를 수 있게 합니다. 클래스나 메서드에 붙입니다. |

공식 `map` 클래스의 `ReplaceKey`와 `GetKeyByValue`에도 `[Obsolete("Use SCR_MapHelper.ReplaceKey")]`처럼 대신 쓸 API를 알려 주는 표시가 붙어 있습니다.

## 이름 규칙과 접두사

### 이름 규칙

공식 위키 Scripting: Conventions를 정리한 표입니다. `TAG_`는 내 모드의 태그로 바꿉니다. Bohemia Interactive의 스크립트에는 `SCR_` 태그가 붙어 있습니다.

| 대상 | 규칙 | 예 |
|---|---|---|
| 태그 | 모든 클래스와 전역 함수, 전역 변수 앞에 붙입니다. `modded` 클래스에 새로 추가하는 메서드와 변수에도 붙입니다. | `TAG_` |
| 파일 | 클래스 이름과 같게 짓습니다. | `TAG_HealthComponent.c` |
| 클래스 | 태그 + PascalCase. 컴포넌트는 `Component`, 엔티티는 `Entity`로 끝냅니다. 합성어 끝에 복수형을 쓰지 않습니다. | `TAG_HealthComponent` |
| 열거형 | 태그 + `E` + PascalCase | `TAG_EWeather` |
| 열거형 값 | 모두 대문자, 단어는 밑줄로 나눔 | `TAG_EWeather.HEAVY_RAIN` |
| 메서드, 함수 | PascalCase | `GetHealth()` |
| 매개변수, 지역 변수 | camelCase | `maxHealth`, `playerName` |
| 멤버 변수 | `m_` + 타입 접두사 + PascalCase | `m_iHealth`, `m_Entity` |
| 정적 변수 | `s_` + 타입 접두사 + PascalCase | `s_iUnitsCount` |
| 전역 변수 | `g_` 접두사. 꼭 필요할 때만 씁니다. | `g_ARGame` |
| 상수 | 모두 대문자, 단어는 밑줄로 나눔. `m_`, `s_`, 타입 접두사를 붙이지 않습니다. | `MAX_VALUE` |

### 타입 접두사

위키의 접두사 정리표입니다. 자식 타입은 부모 타입의 접두사를 따릅니다.

| 타입 | 접두사 | 예 |
|---|---|---|
| `bool` | `b` | `m_bIsEnemy` |
| `int` | `i` | `m_iHealth` |
| `float` | `f` | `m_fSpeed` |
| `string`, `ResourceName`, `LocalizedString` | `s` | `m_sName`, `m_sResourceName` |
| 열거형 | `e` | `m_eState` |
| `vector` | `v` | `m_vPosition` |
| `array`, `Curve` | `a` | `m_aItems` |
| `map` | `m` | `m_mScores` |
| 클래스 인스턴스, `typename`, `set`, `Color` | 접두사 없음 | `m_Entity`, `m_Set` |

### 코드 모양

- 중괄호는 언제나 새 줄에 둡니다(Allman 스타일).
- 들여쓰기는 탭으로 하며, Script Editor에서 탭 크기는 공백 네 칸입니다.
- 이항 연산자 양옆, `foreach`의 콜론 양옆, 상속 콜론 양옆에 공백을 둡니다. `if`, `for`, `foreach`, `switch`, `while` 뒤와 `for` 안의 세미콜론 뒤에도 공백을 둡니다.
- 메서드 사이는 `//` 뒤에 대시 96개를 붙인 줄로 나눕니다.
- 문서 주석은 Doxygen을 고려해 `//!`로 씁니다.
- 멤버 순서는 어트리뷰트가 붙은 변수, 멤버 변수, 정적 변수, 상수 순이며 각각 public, protected, private 순으로 둡니다.
- 인스턴스는 `new TAG_Item()`처럼 괄호를 붙여 만들고, 배열은 `array<string> names = {};`처럼 초기화합니다.
- 변수와 메서드는 밖에 공개할 의도가 없으면 `protected`로 둡니다. 모딩을 고려하면 `private`보다 `protected`를 권합니다(12장).

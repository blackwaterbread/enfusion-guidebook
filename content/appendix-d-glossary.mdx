이 책은 용어마다 한국어 표기를 하나로 정해 두고 일관되게 썼습니다. "장" 열은 그 개념을 주로 설명하는 곳입니다.

## 언어

| 영어 | 이 책의 표기 | 뜻 | 장 |
|---|---|---|---|
| access modifier | 접근 제한자 | 멤버를 어디서 쓸 수 있는지 정하는 키워드. `private`, `protected` | 5 |
| argument | 인수 | 함수를 호출할 때 실제로 넘기는 값 | 4 |
| array | 배열 | 같은 타입의 값을 순서대로 담는 컬렉션. `array<T>` | 8 |
| attribute | 어트리뷰트 | 클래스나 멤버 앞에 대괄호로 붙여 정보를 덧붙이는 문법. 예: `[Attribute()]` | 10 |
| automatic reference counting (ARC) | 자동 참조 카운팅 | 객체를 가리키는 강한 참조의 수를 세다가 0이 되면 객체를 해제하는 메모리 관리 방식 | 7 |
| cast | 형변환 | 값이나 객체를 다른 타입으로 바꿔 다루는 것 | 2, 6 |
| class | 클래스 | 데이터(멤버 변수)와 동작(메서드)을 묶은 타입 | 5 |
| collection | 컬렉션 | 여러 값을 담는 자료구조. 배열, 집합, 맵 | 8 |
| compile | 컴파일 | 소스 코드를 실행할 수 있는 형태로 바꾸는 과정 | 1 |
| constant | 상수 | 한 번 정하면 바꿀 수 없는 값. `const` | 2 |
| constructor | 생성자 | 객체를 만들 때 자동으로 호출되는 메서드. 이름이 클래스와 같음 | 5 |
| destructor | 소멸자 | 객체가 해제될 때 호출되는 메서드. 이름 앞에 `~`를 붙임 | 5 |
| enum | 열거형 | 이름 붙은 정수 상수의 묶음 | 2 |
| expression | 식 | 계산해서 값을 내는 코드 조각 | 2 |
| function | 함수 | 이름을 붙여 다시 쓸 수 있게 만든 코드 묶음 | 4 |
| garbage collection | 가비지 컬렉션 | JavaScript, C# 등이 쓰는 자동 메모리 관리 방식. Enforce Script는 대신 참조 카운팅을 씀 | 7 |
| identifier | 식별자 | 변수, 함수, 클래스 등에 붙이는 이름 | 2 |
| inheritance | 상속 | 기존 클래스의 멤버를 물려받아 새 클래스를 만드는 것 | 6 |
| instance | 인스턴스 | 클래스로 만든 실제 객체 | 5 |
| keyword | 키워드 | 언어가 미리 정해 둔 단어. 식별자로 쓸 수 없음 | 부록 A |
| literal | 리터럴 | 코드에 직접 적은 값. `42`, `"text"` | 2 |
| map | 맵 | 키와 값의 쌍을 담는 컬렉션. `map<TKey, TValue>` | 8 |
| member variable | 멤버 변수 | 클래스에 속한 변수. 관례상 `m_`로 시작 | 5 |
| method | 메서드 | 클래스에 속한 함수 | 5 |
| modded class | modded 클래스 | 기존 클래스를 같은 이름으로 확장하거나 대체하는 Enforce Script 고유 문법 | 12 |
| null | null | 아무 객체도 가리키지 않는 상태 | 5, 7 |
| operator | 연산자 | `+`, `==`, `&&`처럼 값을 계산하거나 비교하는 기호 | 2 |
| overload | 오버로드 | 이름은 같고 매개변수가 다른 함수를 여러 개 두는 것 | 4 |
| override | 오버라이드 | 부모 클래스의 메서드를 자식 클래스에서 다시 정의하는 것. `override` 키워드 | 6 |
| parameter | 매개변수 | 함수가 받기로 선언한 입력 변수 | 4 |
| polymorphism | 다형성 | 같은 부모 타입으로 여러 자식 객체를 다루고, 실제 타입에 맞는 메서드가 실행되는 성질 | 6 |
| preprocessor | 전처리기 | 컴파일 전에 `#ifdef` 같은 지시문을 처리하는 단계 | 부록 A |
| reference | 참조 | 객체를 가리키는 값 | 7 |
| return value | 반환값 | 함수가 실행을 마치고 돌려주는 값 | 4 |
| scope | 스코프 | 변수를 쓸 수 있는 코드 범위 | 2 |
| set | 집합 | 중복 없이 값을 담는 컬렉션. `set<T>` | 8 |
| signature | 시그니처 | 함수의 이름, 매개변수 타입, 반환 타입을 묶어 부르는 말 | 6, 11 |
| static | 정적 | 인스턴스가 아니라 클래스 자체에 속하는 멤버 | 5 |
| strong reference | 강한 참조 | `ref`로 선언한 참조. 객체를 살려 둠 | 7 |
| template | 템플릿 | 타입을 매개변수로 받는 클래스. `array<T>` 등 | 8 |
| typedef | 타입 별칭 | 기존 타입에 다른 이름을 붙이는 문법 | 8 |
| typename | typename | 타입 자체를 값처럼 다루는 타입 | 2, 6 |
| vanilla | 바닐라(원본) | 모드가 적용되지 않은 원래 게임. modded 클래스 안에서는 원본 구현을 가리키는 키워드 | 12 |
| weak reference | 약한 참조 | `ref` 없이 선언한 참조. 객체를 살려 두지 않음 | 7 |

| proxy | 프록시 | 권한자가 아닌 쪽에 있는 복제본 | 14 |
| replication | 리플리케이션 | 서버와 클라이언트의 상태를 맞추는 시스템 | 14 |
| resource | 리소스 | 프리팹, 레이아웃, 텍스처처럼 GUID로 구별하는 파일 | 10, 12 |
| RPC (remote procedure call) | RPC | 다른 머신에서 메서드를 실행해 달라고 요청하는 것 | 14 |
| ScriptInvoker | ScriptInvoker | 여러 콜백을 등록해 두었다가 한 번에 호출하는 이벤트 객체 | 11 |
| server | 서버 | 게임 상태를 관리하고 클라이언트를 받아 주는 쪽 | 14 |
| tag | 태그 | 모드의 클래스 이름 앞에 붙이는 고유 접두사 | 1, 12 |
| user action | 사용자 액션 | 플레이어가 상호작용으로 실행하는 동작 | 16 |
| widget | 위젯 | 버튼, 텍스트, 이미지 같은 UI 구성 요소 | 13 |
| world | 월드 | 엔티티가 존재하는 공간. 하나의 맵 | 10 |
| Workshop | Workshop | 모드를 배포하고 내려받는 공식 플랫폼 | — |

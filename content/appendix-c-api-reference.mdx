title: 자주 쓰는 API
description: 스크립트를 쓰면서 자주 찾게 되는 클래스와 메서드를 분야별로 모았습니다. 시그니처, 한 줄 설명, 정의된 파일을 한눈에 봅니다.
---

모든 시그니처는 Arma Reforger 1.8.0.13 공식 스크립트에서 확인했습니다.

표를 읽는 방법은 다음과 같습니다.

- 메서드는 `반환타입 클래스.메서드(매개변수)` 꼴로 적었습니다. 정적 메서드에는 앞에 `static`을 붙였고, 엔진이 호출하는 이벤트 메서드는 설명에 "(이벤트)"라고 표시했습니다. 이벤트 메서드는 자식 클래스에서 `override`로 다시 정의해 씁니다.
- 기본값이 있는 매개변수가 길게 이어지는 경우 뒤쪽을 `...`로 줄였습니다. 전체 선언은 정의 파일에서 확인하세요.
- "정의 파일"은 공식 스크립트의 `scripts` 폴더를 기준으로 한 경로입니다. Script Editor의 **Projects** 창에서 열거나, **Find Symbol**로 이름을 검색해 찾을 수 있습니다.
- 각 절 끝에 그 분야를 자세히 설명한 장을 적었습니다.

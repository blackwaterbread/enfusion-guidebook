<Answer id="15-1">

`PrintFormat`의 선언은 `PrintFormat(string fmt, void param1 = NULL, ..., void param9 = NULL, LogLevel level = LogLevel.NORMAL)`입니다. `LogLevel.WARNING`을 세 번째 인수로 쓰면 두 번째 형식 인수 `param2` 자리에 들어갑니다. 형식 문자열에 `%2`가 없으니 출력에는 나타나지도 않고, 메시지는 기본 수준인 `NORMAL`로 기록됩니다. 그래서 `-logLevel warning`으로 걸러 보면 빠집니다.

`level`을 이름 있는 인수로 넘기면 됩니다.

```enforce
if (remaining == 0)
	PrintFormat("상자 %1이 비었습니다.", crateName, level: LogLevel.WARNING);
```

`Print`는 매개변수가 `Print(void var, LogLevel level)` 두 개뿐이므로 `Print("...", LogLevel.WARNING)`처럼 위치 인수로 넘겨도 됩니다.

</Answer>

<Answer id="15-4">

`EOnFrame`과 이벤트 마스크를 없애고, `OnPostInit`에서 콜 큐에 1초 간격의 반복 호출을 등록합니다. 반복 호출은 컴포넌트가 삭제될 때 `OnDelete`에서 해제합니다.

```enforce title="Scripts/Game/TAG_FuelWarningComponent.c"
[ComponentEditorProps(category: "TAG/Tutorial", description: "연료 경고")]
class TAG_FuelWarningComponentClass : ScriptComponentClass
{
}

class TAG_FuelWarningComponent : ScriptComponent
{
	protected static const int CHECK_INTERVAL_MS = 1000;

	override void OnPostInit(IEntity owner)
	{
		if (!GetGame().InPlayMode())
			return;	// World Editor 편집 중에는 타이머를 돌리지 않는다

		GetGame().GetCallqueue().CallLater(UpdateWarning, CHECK_INTERVAL_MS, true);
	}

	override void OnDelete(IEntity owner)
	{
		GetGame().GetCallqueue().Remove(UpdateWarning);
	}

	protected void UpdateWarning()
	{
		// 연료량을 확인하고 경고를 갱신한다
	}
}
```

`CallLater(함수, 지연 밀리초, 반복 여부)`에서 세 번째 인수 `true`가 반복입니다. 공식 컴포넌트들(`SCR_NetworkedStatsComponent` 등)도 `OnDelete`에서 반복 호출을 해제합니다. `OnPostInit()`은 World Editor 편집 중에도 불리므로(10장) `GetGame().InPlayMode()`로 게임 중일 때만 타이머를 등록했습니다.

이 컴포넌트가 수백 개 있어도 매 프레임 호출이 사라지니, 위키 성능 문서의 "이렇게 자주 해야 하나?"에 대한 답이 됩니다.

</Answer>

계산만 하는 클래스는 테스트 코드에서 엔티티를 만들거나 월드를 준비할 필요가 없습니다. 그래도 테스트를 실행하는 데는 플레이 모드와 월드가 쓰입니다. Autotest 플러그인과 Autotest Tool은 Workbench 안에서 실행할 때 플레이 모드로 바꿉니다. 1.8.0.13 Workbench에서 실행해 보면 케이스는 플레이 모드가 시작된 뒤에야 돌았고, 이 해답의 스위트처럼 `GetWorldFile()`을 오버라이드하지 않은 스위트는 그 전에 기본 Autotest 월드를 열었습니다. `TAG_SupplyMath`는 게임 코드가 쓰는 클래스이므로 `#ifdef WORKBENCH` 바깥에 둡니다.

```enforce title="Scripts/Game/TAG_SupplyMath.c"
//! 보급품 수량 계산
class TAG_SupplyMath
{
	//! 남은 수량. 0보다 작아지지 않는다.
	static int GetRemaining(int capacity, int taken)
	{
		int remaining = capacity - taken;
		if (remaining < 0)
			return 0;

		return remaining;
	}

	//! 하나 더 가져갈 수 있으면 true
	static bool CanTake(int capacity, int taken)
	{
		return GetRemaining(capacity, taken) > 0;
	}
}
```

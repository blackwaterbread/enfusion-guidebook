### API 레퍼런스

공식 스크립트의 문서화 주석으로 만든 Doxygen 문서입니다. 클래스와 메서드를 찾아보거나 상속 관계를 확인할 때 씁니다.

- [Arma Reforger Script API](https://community.bistudio.com/wikidata/external-data/arma-reforger/ArmaReforgerScriptAPIPublic/): 게임 쪽 클래스(`SCR_` 접두사 등)
- [Enfusion Script API](https://community.bistudio.com/wikidata/external-data/arma-reforger/EnfusionScriptAPIPublic/): 엔진 쪽 클래스와 내장 타입

### Workbench 동봉 엔진 문서

Arma Reforger Tools 설치 폴더의 `Workbench/docs` 아래에는 Enfusion Script API 문서가 들어 있고, 그 안에 엔진 해설 페이지(Pages)가 함께 실려 있습니다. 위키보다 엔진 자체를 자세히 설명하며, 이 책은 특히 다음 페이지를 많이 참고했습니다.

- Syntax, Values, Keywords, Operators: 언어 문법
- Enforce Automatic Reference Counting: 메모리 관리
- Event System, Loadtime and Runtime, World Systems: 엔진 구조
- Replication, Replicating entities, components and hierarchies, RplNode: 멀티플레이어
- Language Server Protocol, Features, Visual Studio Code configuration: 외부 편집기 연동(1장)

## 공식 저장소

Bohemia Interactive가 GitHub에 공개한 저장소입니다.

- [BohemiaInteractive/Arma-Reforger-Script-Diff](https://github.com/BohemiaInteractive/Arma-Reforger-Script-Diff): 게임 스크립트 전체. 버전마다 무엇이 바뀌었는지 커밋 기록으로 확인할 수 있습니다. 이 책의 모든 API는 1.8.0.13 버전의 이 저장소에서 확인했습니다.
- [BohemiaInteractive/Arma-Reforger-Samples](https://github.com/BohemiaInteractive/Arma-Reforger-Samples): 공식 샘플 모드. 스크립트 수정, 새 무기, 새 차량, Workbench 플러그인 예제가 들어 있습니다.
- [BohemiaInteractive/Arma-Reforger-Misc](https://github.com/BohemiaInteractive/Arma-Reforger-Misc): 모더를 위한 추가 자료

<Tip title="공식 스크립트를 내려받아 두세요">

Arma-Reforger-Script-Diff를 내려받아 두면 클래스 이름이나 메서드 이름으로 바로 검색할 수 있습니다. 공식 코드가 어떤 메서드를 실제로 어떻게 쓰는지 보는 것만큼 좋은 교재는 없습니다. Windows에서는 경로가 길어 클론이 실패할 수 있으니 `git config --global core.longpaths true`를 먼저 설정하세요.

</Tip>

## 편집기 도구

- **Workbench Script Editor의 LSP**: Bohemia Interactive가 실험적으로 제공하는 언어 서버입니다. VS Code 같은 외부 편집기에서 자동완성과 진단을 받을 수 있습니다(1장).
- [Reforger Script Tools](https://marketplace.visualstudio.com/items?itemName=Burn0ut7.reforger-script-tools): 커뮤니티가 만든 VS Code 확장입니다. 문법 강조, 자동완성, 정의로 이동을 지원합니다.
- [tree-sitter-enforce](https://github.com/simonvic/tree-sitter-enforce): Enforce Script용 tree-sitter 문법입니다. Neovim 같은 편집기에서 구문 강조에 씁니다.

## Enfusion Workbench 가이드

같은 저자의 《Enfusion Workbench 가이드》(이하 Workbench 가이드)는 Arma Reforger Tools의 Workbench를 화면과 절차 중심으로 다룹니다. 이 책이 스크립트를 맡고, 예제를 실행할 때 쓰는 메뉴와 창, 작업 순서는 Workbench 가이드가 자세히 설명합니다. 이 책의 장과 가까운 Workbench 가이드의 장은 다음과 같습니다.

| 이 책 | Workbench 가이드 |
|---|---|
| 1장 | 1장 설치와 프로젝트, 4장 Script Editor |
| 10장 | 6장 World Editor 기초, 7장 컴포넌트와 속성, 8장 프리팹 |
| 12장 | 3장 Resource Browser, 9장 설정 파일 |
| 13장 | 10장 레이아웃과 문자열 테이블 |
| 14장 | 12장 멀티플레이와 테스트 도구 |
| 15장 | 5장 콘솔, 로그, 디버거, 11장 Play와 Diag Menu, 12장 멀티플레이와 테스트 도구 |
